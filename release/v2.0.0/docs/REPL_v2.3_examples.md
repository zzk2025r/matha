# Matha v2.3 REPL 交互示例

## 启动方式

```bash
python main.py              # 启动 REPL
python main.py --demo       # 运行演示
python main.py --test       # 运行测试
```

## 可用命令

| 命令 | 说明 |
|---|---|
| `mode <matha\|nl\|intent>` | 切换交互模式 |
| `history` | 显示输入历史 |
| `errors` | 查看所有错误记录 |
| `recover` | 尝试自动恢复最近错误 |
| `explain <text>` | 解释自然语言意图 |
| `intent <text>` | 深度意图分析 |
| `clear` | 清屏 |
| `quit` / `exit` | 退出 |
