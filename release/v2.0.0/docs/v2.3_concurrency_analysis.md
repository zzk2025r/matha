# v2.3 异常处理架构 — 并发安全分析报告

## 1. 当前架构并发问题

### 1.1 RecoveryStrategy 类变量竞争

```python
class RecoveryStrategy:
    _strategies: dict[ErrorStage, list] = {}  # 类级别共享字典
```

**问题**：`_strategies` 是类级别变量，所有实例共享。多线程同时注册/遍历策略时存在竞争。

| 风险等级 | 问题描述 |
|---|---|
| 🔴 高 | `_strategies[stage].append(fn)` 非原子操作 |
| 🟡 中 | `try_recover()` 遍历时列表可能被修改 |

**证明**：`test_concurrent_parse` 中 5 个线程同时创建 EnhancedIntentParser，
虽然每次调用 `classify()` 独立，但 `RecoveryStrategy._strategies` 的写入无锁保护。

### 1.2 MathaError 实例状态可变

```python
class MathaError(Exception):
    def add_suggestion(self, suggestion: str):
        if suggestion not in self.suggestions:
            self.suggestions.append(suggestion)  # 可变列表，线程不安全
        return self
```

**问题**：`add_suggestion()` 修改实例状态，若在多线程中共享同一 `MathaError` 实例，
会导致数据竞争。

### 1.3 EnhancedIntentParser 实例状态

```python
class EnhancedIntentParser(IntentParserBase):
    def __init__(self):
        self.classifier = IntentClassifier()  # 无状态，安全
        self.extractor = ParamExtractor()     # 无状态，安全
        self.generator = CodeGenerator()      # 无状态，安全
```

**现状**：当前实现无共享可变状态，**线程安全**。每个 `parse()` 调用创建独立的
`Intent` 对象，无共享可变状态。

### 1.4 REPL State 并发访问

```python
@dataclass
class REPLState:
    error_log: list[MathaError] = field(default_factory=list)  # 可变列表
```

**问题**：若 REPL 支持多线程输入（如异步 REPL），`error_log.append()` 存在竞争。
**现状**：单线程 REPL，暂无问题。

## 2. 优化方案

### 2.1 为 RecoveryStrategy 添加读写锁

```python
import threading

class RecoveryStrategy:
    _strategies: dict[ErrorStage, list] = {}
    _lock = threading.RLock()  # 重入锁

    @classmethod
    def register(cls, stage: ErrorStage):
        def decorator(fn):
            with cls._lock:  # 写锁
                if stage not in cls._strategies:
                    cls._strategies[stage] = []
                cls._strategies[stage].append(fn)
            return fn
        return decorator

    @classmethod
    def try_recover(cls, error: MathaError) -> Optional[MathaError]:
        with cls._lock:  # 读锁（副本遍历）
            strategies = list(cls._strategies.get(error.stage, []))
        for strategy in strategies:
            try:
                result = strategy(error)
                if result is not None:
                    with cls._lock:
                        error.add_suggestion(f"恢复策略成功: {strategy.__name__}")
                    return result
            except Exception:
                continue
        return None
```

### 2.2 MathaError 不可变化（推荐）

将 `suggestions` 改为不可变操作：

```python
class MathaError(Exception):
    def __init__(self, ..., suggestions: list = None):
        # 不直接修改，而是创建新列表
        self._suggestions = list(suggestions or [])

    def add_suggestion(self, suggestion: str) -> "MathaError":
        # 返回新实例而非修改自身
        new = MathaError(
            message=self.message,
            stage=self.stage,
            suggestions=self._suggestions + [suggestion],
            # ... 其他字段
        )
        return new
```

**代价**：错误对象不可复用，需调整 `with_cause` 等方法的调用方式。

### 2.3 REPL error_log 加锁

```python
class REPLState:
    def __init__(self):
        self._error_log: list[MathaError] = []
        self._error_lock = threading.Lock()

    @property
    def error_log(self):
        with self._error_lock:
            return list(self._error_log)

    def append_error(self, error: MathaError):
        with self._error_lock:
            self._error_log.append(error)
```

### 2.4 使用线程本地存储（ThreadLocal）

对于不需要全局共享的上下文：

```python
import threading

_thread_local = threading.local()

def get_parse_context():
    if not hasattr(_thread_local, 'context'):
        _thread_local.context = {}
    return _thread_local.context
```

## 4. 推荐优先级

| 优先级 | 优化项 | 风险等级 | 实施难度 |
|---|---|---|---|
| P0 | REPL error_log 加锁 | 🟡 中 | 低 |
| P1 | RecoveryStrategy 读写锁 | 🔴 高 | 中 |
| P2 | MathaError 不可变化 | 🟡 中 | 高 |
| P3 | 线程本地上下文 | 🟢 低 | 中 |

**当前结论**：对于单线程 REPL 场景，当前实现**功能正确**。若未来支持
异步/多线程输入，需实施 P0/P1 优化。
