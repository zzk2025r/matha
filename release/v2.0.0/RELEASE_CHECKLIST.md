## 一、性能提升数据

### 1.1 启动流程优化（懒加载缓存）

| 指标 | 优化前 | 优化后 | 提升 |
|---|---|---|---|
| 首次 grow() 调用 | ~170ms | ~115ms | 32% |
| 后续 grow() 平均 | ~170ms | ~2.7ms | **50x** |
| 跨实例调用 | ~170ms | ~2.5ms | **68x** |
| 单次节省 | - | ~131ms | **98.0%** |

**实现方案**: 类级缓存 `_interpret_cache`，首次导入后缓存 `interpret` 函数引用，后续所有实例共享。

| 规则 | 单次耗时 | 复杂度 | 累计占比 |
|---|---|---|---|
| 常量折叠 | <0.1ms | O(n) | ~5% |
| 死代码消除 | <0.1ms | O(n²) | ~5% |
| 常量传播 | <0.5ms | O(n×迭代) | ~8% |
| 函数内联 | ~30ms | O(n×轮) | ~40% |
| 循环展开 | <1ms | O(n) | ~3% |
| 栈式命名 | <0.5ms | O(n²) | ~5% |
| 三角恒等式 | <0.01ms | O(1) | ~1% |
| **优化逻辑总计** | **~75ms** | | **~35%** |

## 三、新增优化规则

| 规则 ID | 名称 | 描述 | 触发条件 |
|---|---|---|---|
| OPT-001 | 常量折叠 | `x = 3.0 + 4.0` → `x = 7.0` | 右侧为纯常量表达式 |
| OPT-002 | 死代码消除 | 移除无后续引用的赋值 | 变量赋值后无引用 |
| OPT-003 | 常量传播 | `a=10; b=a+5` → `b=10+5` | 变量赋值为常量且后续使用 |
| OPT-004a | 函数内联（单用） | `def f(x): return x*x; f(3)` → `3*3` | 函数只被调用一次 |
| OPT-004b | 递归内联 | 递归函数深度受限展开 | 递归函数且只调用一次 |
| OPT-005 | 循环展开 | `for i in range(N)` → 顺序语句 | N ≤ 8 且单行 body |
| OPT-006 | 内存优化 | 赋值链 `a→b→c` 合并 | 三行链式赋值 |
| OPT-007 | 三角恒等式 | `sin+cos(π/2-x)` 简化 | sin+cos 组合 |

## 五、已知限制

| 限制 | 说明 | 优先级 |
|---|---|---|
| 模块导入开销 | 首次调用仍耗时 ~128ms | 低 |
| 递归内联深度 | 最大 5 层，深层递归不展开 | 低 |
| 循环展开倍数 | 最大 8 次，大循环不展开 | 低 |
| 多语言一致性 | Python 源码在 C/Go/Rust 前端无函数属正常 | 已知 |
| 栈式命名 | 仅对存活区间 >1 的变量生效 | 低 |
