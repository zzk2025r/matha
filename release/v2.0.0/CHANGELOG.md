# Changelog — Matha 自成长引擎 v2.1

## [v2.1.0] — 2025-07-26

### ⚡ 性能优化

- **懒加载解释器**：引入类级缓存 `_interpret_cache`，解释器模块首次导入后缓存，后续调用直接复用
  - 后续 grow() 调用耗时从 ~170ms 降至 ~2.7ms，**加速 50x**
  - 跨实例调用共享同一缓存，加速 **68x**
  - 累计节省 ~112ms/次（98.0%）

### 🚀 新增优化规则

- **OPT-006 栈式命名优化**：变量存活范围分析 + 区间着色算法，识别互不相交的存活区间并复用槽位，减少命名空间污染
- **OPT-005 循环展开增强**：行扫描精确匹配 + 嵌套块自动跳过 + 累加器变量保护，确保展开语义正确

### 📝 修复

- 修复解释器模块每次 grow() 调用重复导入的性能问题
- 修复循环展开在多行 body 时误展开的问题
- 修复循环展开与常量传播对累加器变量的冲突

### 📊 性能数据

| 场景 | 耗时 | 优化效果 |
|---|---|---|
| 简单加法 | ~188ms | 折叠×1, DCE×1, 传播×1 → result=7.0 |
| 嵌套函数链 | ~23ms | 内联×3 + 折叠 + 传播 → result=30.0 |
| 常量链(8步) | ~32ms | 折叠×1, DCE×3, 传播×1 → result=21.0 |
| 混合优化 | ~51ms | DCE×3, 折叠×1, 传播×1 → result=75.0 |
| **后续调用** | **~2.7ms** | **缓存命中，50x 加速** |
