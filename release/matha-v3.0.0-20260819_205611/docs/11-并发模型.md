# 11 - 并发模型

> 本章定义 Matha 的并发模型：基于 CSP（Communicating Sequential Processes），轻量协程通过 channel 通信，不通过共享内存传递状态。

---

## 1. 设计哲学

Matha 采用 CSP 而非共享内存+锁，理由（见 [01-设计原则 §原则六](01-设计原则.md)）：
- **可推理**：并发单元隔离，通过显式 channel 通信。
- **可读可验证**：通信路径显式，契合 Matha 整体哲学。
- **可组合**：channel 是一等值，可传递、可类型化。

---

## 2. 协程（轻量线程）

### 2.1 启动协程

```
go <expr>
```

`go` 启动一个轻量协程执行表达式（草案关键字）。

```
go producer(ch)        (* 启动生产者协程 *)
go consumer(ch)        (* 启动消费者协程 *)
```

> **候选符号化**：`#：《并发》 expr` 或 `<<go>> expr`。当前用 `go` 关键字，待确认是否符号化。

---

## 3. Channel

Channel 是协程间通信的管道，是一等值，有类型。

### 3.1 创建

```
chan <type>            (* 无缓冲 channel *)
chan <type> , <n>      (* 缓冲为 n 的 channel，草案 *)
```

```
ch = chan Int                  (* 无缓冲 Int channel *)
ch2 = chan Int, 10             (* 缓冲 10，草案语法 *)
```

### 3.2 发送与接收

| 操作 | 语法 | 语义 |
|------|------|------|
| 发送 | `ch <- v` | 将 v 发送到 ch |
| 接收 | `v <- ch` | 从 ch 接收（阻塞） |
| 接收表达式 | `<- ch` | 接收并返回值 |

```
ch <- 42            (* 发送 42 *)
v = <- ch           (* 接收到 v *)
[] <- ch            (* 接收并输出 *)
```

> **方向消歧**：`ch <- v`（左为 channel，发送）vs `v <- ch`（右为 channel，接收）。由操作数位置决定。

---

## 4. select

`select` 同时等待多个 channel 操作，执行最先就绪的一个：

```
select
   | v <- ch1 => ...       (* ch1 可接收时 *)
   | ch2 <- v => ...       (* ch2 可发送时 *)
   | 否则 => ...           (* 超时/默认，草案 *)
```

`|` 分格各分支（见 [07 §6](07-语句与控制流.md)）。

---

## 5. 示例：生产者-消费者

```
producer : chan Int -> Unit = (ch) =>
   ？x >> { n | 1 <= n <= 5 }
      ch <- x
   ch <- -1              (* 结束信号 *)

consumer : chan Int -> Unit = (ch) =>
   loop
      v = <- ch
      v = -1 ? break : [] v

main = #：
   ch = chan Int
   go producer(ch)
   go consumer(ch)
```

> `loop`/`break` 为草案关键字（见 [07 §4](07-语句与控制流.md) 待确认项）。

---

## 6. 同步原语

| 原语 | 语义 | 草案语法 |
|------|------|---------|
| 无缓冲 channel | 同步握手 | `chan T` |
| 缓冲 channel | 异步至满 | `chan T, n` |
| 关闭 | 关闭 channel | `close ch` |
| 超时 | 限时等待 | `select` + `否则` |

> **不提供共享内存锁**：Matha 不鼓励 `mutex`/`lock`。需共享状态时，用 channel 封装（"不要通过共享内存通信，而通过通信共享内存"）。

---

## 7. 类型与安全

- Channel 类型：`Chan[T]`（待 [05-类型系统](05-类型系统.md) 扩展）。
- 发送/接收类型检查：`ch : Chan[Int]` 则 `ch <- "a"` 类型错误。
- 关闭后发送触发运行时错误（见 [12-错误处理](12-错误处理.md)）。

---

## 8. Python 运行时映射（草案）

Matha 的协程在 Python 实现中映射到：
- **asyncio** 协程（轻量，单线程事件循环）
- 或 **threading**（OS 线程，用于阻塞操作）

详见 [15-编译执行模型](15-编译执行模型.md)。

## 9. EBNF 摘要

```ebnf
<go_stmt>     = "go" , <expr> ;
<chan_expr>   = "chan" , <type_expr> , [ "," , <integer> ] ;
<send_expr>   = <expr> , "<-" , <expr> ;      (* ch <- v *)
<recv_expr>   = "<-" , <expr> ;                (* <- ch *)
<select_stmt> = "select" , { "|" , <select_branch> } ;
<select_branch> = <recv_or_send> , "=>" , <expr> ;
```
