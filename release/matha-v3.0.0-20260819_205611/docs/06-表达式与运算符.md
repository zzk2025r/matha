# 06 - 表达式与运算符

> 本章定义 Matha 的表达式语法、运算符的优先级与结合性、各类运算的语义，以及 `？` 占位、`<<` 角度、`>>` 步进/属于等符号在表达式层的行为。

---

## 1. 表达式优先级与结合性

从低到高（同行同级）：

| 级别 | 运算符 | 结合性 |
|------|--------|--------|
| 1 | `|`（分格，在表达式中为序列分隔） | 左 |
| 2 | `<` `>` `<=` `>=` `=`（关系） | 无 |
| 3 | `+` `-`（加减） | 左 |
| 4 | `*` `/`（乘除） | 左 |
| 5 | `^`（次方，中缀） | 右 |
| 6 | `<<`（角度，前缀）、`^`（开方，前缀）、`>>`（步进/属于） | — |
| 7 | `-`（一元负）、函数应用、`[]` `【】` 包裹 | — |
| 8 | 字面量、变量、`( )` 分组、`@( ... )` 设定 | — |

> **`^` 的双语义**：中缀 `^`（前有操作数）为次方（级 5，右结合）；前缀 `^`（前无操作数）为开方（级 6，前缀一元）。位置消解在语法层依据前一个 Token 判定。
>
> **词法最长匹配优先**：`<<`、`>>`、`<=`、`>=` 优先于单字符 `<`、`>`。

---

## 2. 算术运算符

| 运算符 | 语义 | 示例 |
|--------|------|------|
| `+` | 加 | `2 + 3 = 5` |
| `-` | 减 / 一元负 | `5 - 2 = 3`；`-x` |
| `*` | 乘 | `2 * 3 = 6` |
| `/` | 除 | `6 / 2 = 3` |
| `^`（中缀） | 次方（右结合） | `3^2 = 9`；`2^3 = 8`；`2^2^3 = 2^(2^3) = 256` |
| `^`（前缀） | 开方（平方根） | `^9 = 3`（因 `3*3=9`）；`^16 = 4`；等价 `n^(1/2)` |

**`^` 双语义消解**（已确认）：`^` 前有操作数（字母/`？`/数字/`)` 等）时为中缀次方；前无操作数（位于表达式起点或运算符/分隔符之后）时为前缀开方。开方是次方的逆运算——`^9 = 3` 因 `3^2 = 9`。

**类型规则**：`Int op Int : Int`（`/` 视语义为整除或精确除，待确认）；`Float op Float : Float`；`^n : Float`（开方结果视输入类型，`^9 : Int` 当 9 为完全平方数，否则 `Float`，待确认）。

---

## 3. 关系运算符

| 运算符 | 语义 | 示例 |
|--------|------|------|
| `<` | 小于 | `2 < 3` 为真 |
| `>` | 大于 | `3 > 2` 为真 |
| `<=` | 小于等于 | `2 <= 2` 为真 |
| `>=` | 大于等于 | `3 >= 3` 为真 |
| `=` | 等于 | `2 = 2` 为真 |

**返回类型**：`Bool`。

> **`=` 的双重语义**：在绑定语境为赋值（`x = 5`），在表达式语境为相等判断（`x = 5` 作为表达式返回 Bool）。消解规则：出现在 `mech_stmt` 首位且左侧为变量时为赋值；否则为相等判断。详见 [07-语句与控制流](07-语句与控制流.md)。

> **统一约定**：采用 `<=` `>=`（主流形式）。早期示例中的 `=<` 已统一为 `<=`。

---

## 4. 角度运算 `<<`

`<<` 是**一元前缀**角度标记，将其后的数值解释为角度（度）：

```
<<90            (* 90 度 *)
<<180           (* 180 度 *)
sin(<<30)       (* 30° 的正弦 *)
cos(<<90)       (* 90° 的余弦，≈ 0 *)
```

**优先级**：6（高于算术，低于分组）。

**类型**：`<<n` 产生角度类型 `Angle`（草案，待标准库定义），可传入三角函数。

## 5. 步进 / 属于 / 路径距离 `>>`

`>>` 统一为"下一个 / 到 / 下一级"，按语境消解为三种语义：

### 5.1 步进迭代（语句语境）

`？x >> S` —— `x` 依次取 `S` 中的下一个元素，用于循环遍历：

```
？x >> S
   sum = sum + x
```

详见 [07-语句与控制流](07-语句与控制流.md)。

### 5.2 属于判断（表达式语境）

`x >> S` 作为表达式，当 `x` 属于 `S` 时为真：

```
x >> S          (* x ∈ S，返回 Bool *)
```

**消解规则**：`>>` 出现在循环头部（后跟语句体）为步进；出现在表达式位置（如条件、`|` 分隔的条件）为属于判断。

### 5.3 路径 / 距离（绑定/设定语境）

当 `>>` 出现在绑定或设定项的左侧（`a>>b = ...`，或出现在 `@:` / `@(...)` 项中），表示「从 a 到 b 的路径/距离」：

```
a>>b = 100米                (* a 到 b 的距离 = 100 米，单位 米 为字符串 *)
@:a>>b=100米，b>>c=50米      (* @: 形式中直接写路径距离 *)
```

**消解规则**：`>>` 所在的整体出现在 `=` 左侧（绑定的被赋值者）或出现在 `@` 设定项内时，为路径/距离语义。路径本身是一个可被计算/引用的值。路径可组合：`a>>c = a>>b + b>>c`。

> 单位 `米/秒/千克` 等只作为附加字符串存在，语义层不做量纲换算（已确认：单位只是字符串）。

## 6. 集合运算

基于集合论（详见 [04-数学核心 §3](04-数学核心（机械语言）.md)）：

| 运算 | 形式（草案） | 语义 |
|------|------------|------|
| 并 | `A ∪ B` | 并集 |
| 交 | `A ∩ B` | 交集 |
| 差 | `A \ B` | 差集 |
| 补 | `~A` | 补集（相对全集） |
| 笛卡尔积 | `A × B` | 笛卡尔积 |
| 属于 | `x >> S` | 成员判断（见 §5.2） |
| 子集 | `A ⊆ B` | 子集判断 |

> **符号确认**：集合运算的符号形式（`∪∩\~` 等 Unicode 符号 vs ASCII 替代如 `+|*`）**待确认**。倾向使用 Unicode 数学符号以契合"数学即代码"哲学，但需考虑输入便利性。

**集合构造表达式**：

```
{ x | 条件 }                       (* 满足条件的 x *)
{ (x, y) | x >> A | y >> B | x < y }   (* 多变量多条件，| 分格 *)
```

## 7. 函数应用

```
f e                (* 函数 f 应用于参数 e *)

g (a, b)           (* 元组参数 *)
```

**优先级**：7（高于运算符）。`f a + b` 解析为 `(f a) + b`。

函数定义与高阶函数见 [08-函数与抽象](08-函数与抽象.md)。

## 8. `？` 占位、变量绑定与 `@` 设定

- `？` 在**公式模板**中表示通用变量占位（可用任意字母替代）：
  ```
  #：？+？=？            (* 通用加法公式模板 *)
  ```
- 在**具体程序**中用具名字母：
  ```
  #：a + b = c
  ```
- `？` 不参与运行时求值，仅用于公式生成与模式匹配（见 [08-函数与抽象](08-函数与抽象.md) 的模式匹配）。

### 8.1 `@` 设定表达式

`@` 用于**设定**一组标识符/变量/参数，两种等价形式：

**形式一** `@(...)`（`|` 分格，紧凑）：
```
@(a1 | d | c6)                        (* 设定三个变量 *)
@(x*/Int/* | y*/Int/* | z*/Int/*)     (* 设定并标注类型 *)
@(p*/约束*p >= 0/* | q*/约束*q >= 0/*) (* 设定并带标注公式 *)
```

**形式二** `@:` / `@：`（中文逗号 ， 分格，手写友好）：
```
@:a>>b=100米，b>>c=50米，c>>d = (a>>c) * 3    (* 设定路径距离，中文逗号 *)
@:x*/Int/*, y*/Int/*                           (* 英文逗号也合法 *)
```

- 每项为一个变量，可携带 `*/文字/*` 或 `*/文字*公式/*` 标注，也可直接写成完整绑定（`a>>b=100米`）。
- `@` 设定作为表达式（级 8），产出一组绑定视图，用于批量声明、参数列举、配置、条件设定。
- 语法见 [02 §2.8](02-词法结构.md)，语义见 [04 §5.10](04-数学核心（机械语言）.md)。

### 8.2 单位（纯字符串）

单位如 `米、秒、千克、元` 等直接跟在数值后面，作为数值的附加字符串，不进行量纲换算或类型化处理（已确认：单位只是字符串）。

```
100米        (* 100 后面跟字符串「米」 *)
262.5米      (* 浮点数后跟单位 *)
50秒         (* 秒 *)
```

解析策略：`100米` 解析为 `数值 100` 外加一个字符串标签；运算时数值部分参与计算，输出时标签拼接回去（如 `100米+50米 = 150米`）。单位不做严格校验，仅作为输出的可读标签。

## 9. 读取与输出表达式

| 形式 | 语义 |
|------|------|
| `【 content 】` / `〔 content 〕` | 读取内容（值/自然语言/命令） |
| `[ expr ]` | 输出表达式的结果 |

**示例**：

```
【*/问候/*】 输出"你好"        (* 读取自然语言意图 *)
[] "你好"                     (* 输出字符串 *)
[] (2 + 3)                    (* 输出 5 → [5] *)
```

### 9.1 输出 + 循环后缀（段级 / 全局，硬性区分）

`[ expr ]` 输出后可紧跟**段级循环后缀**（单 `…`）或**全局循环后缀**（双 `……`），或两者组合（段级 → 全局编号 → 全局）。

| 形式 | 语义 |
|---|---|
| `[输出]…N（x/y）` / `[输出]…N(x/y)` | 段级循环：段 N，总 y 次，当前 x 次；括号半/全角均合法 |
| `[输出]……（x/y）` / `[输出]……(x/y)` | 全局循环：整个代码总 y 次，当前 x 次 |
| `[输出]…2（0/4）00001……（0/1）` | 段级 2 循环 + 全局编号 00001 + 全局循环（组合使用） |

**省略号硬性区分（M3 已确认）：**
- 单 `…` → **段级循环**（接段号 + 分数）
- 双 `……` → **全局循环**（直接接分数）

半角/全角括号等价：`(0/1)` = `（0/1）`。

```ebnf
(* 输出 + 段循环 + 子文件 + 全局编号 + 全局循环 + 文件路径（M3.3：按位置区分子文件/文件） *)
<output_trail>  = <output>
                , [ <seg_loop_suffix>
                  , [ <subfile_ref> ]                              (* 段循环后：子文件，| 分隔多个 *)
                  , [ <global_code_id> ]
                  , [ <global_loop_suffix> , [ <file_ref> ] ]     (* 全局循环后：文件路径 *)
                  ] ;
<subfile_ref>    = ( "【" | "〔" ) , <path_content> , { "|" , <path_content> } , ( "】" | "〕" ) ;
<file_ref>       = ( "【" | "〔" ) , <path_content> , ( "】" | "〕" ) ;
(* 循环后缀定义来自 02 §2.10 *)
<seg_loop_suffix>    = "…" , [ <seg_id> ] , <loop_fraction> ;
<global_loop_suffix> = "……" , <loop_fraction> ;
<loop_fraction>      = ( "(" | "（" ) , <digit_seq> , "/" , <digit_seq> , ( ")" | "）" ) ;
(* 全局代码编号：任意位数字，不固定位数 *)
<global_code_id>     = <digit> , { <digit> } ;
(* >> 通用链式表达式：连接任意语句（M3.1 已确认） *)
<chain_expr>         = <expr> , { ">>" , <expr> } ;
```

## 10. 模式匹配（草案）

Matha 计划支持基于集合论与代数数据类型的模式匹配：

```
match x
  | 0 -> "零"
  | n >> S -> "在集合中"
  | _ -> "其他"
```

## 11. EBNF 摘要

```ebnf
<expr>      = <rel_expr> ;
<rel_expr>  = <add_expr> , [ <rel_op> , <add_expr> ] ;
<add_expr>  = <mul_expr> , { ("+" | "-") , <mul_expr> } ;
<mul_expr>  = <pow_expr> , { ("*" | "/") , <pow_expr> } ;
<pow_expr>  = <unary> , [ "^" , <pow_expr> ] ;          (* 中缀次方，右结合 *)
<unary>     = [ "-" | "^" ] , <postfix> ;               (* ^ 前缀开方 / - 一元负 *)
<postfix>   = <primary> , { <primary> } ;               (* 函数应用 *)
<primary>   = <integer> | <float> | <string> | <variable>
            | <angle_expr> | <set_construct> | <read_block>
            | <output> | <set_up> | "(" , <expr> , ")" ;
<angle_expr> = "<<" , <expr> ;                          (* 角度 *)
<belongs>   = <expr> , ">>" , <expr> ;                  (* 属于判断 *)
<set_up>    = "@" , "(" , <set_up_item> , { "|" , <set_up_item> } , ")" ;
<set_up_item> = <variable> , [ <annotation> ] ;         (* 可带标注公式 *)
<annotation> = "*/" , <annot_text> , [ "*" , <expr> ] , "/*" ;   (* 文字 + 可选公式 *)
```

## 11. 进制字面量与转译（M3.4）

### 11.1 进制字面量在表达式中

进制字面量（[02 §5.1.1](02-词法结构.md)）作为 `<primary>` 的整数形式参与表达式运算，其值在 parser 层已按前缀转换为十进制 `int`：

```
#1：[0b1010 + 0t210]   → 10 + 21 = 31
x = 0xFF * 2           → 255 * 2 = 510
y = 0b1111             → 15
```

### 11.2 二进制/三进制转译

Matha 提供数值与二进制/三进制字符串的互相转译（`src/binary_codec.py`）：

| 转译方向 | 函数 | 示例 |
|---------|------|------|
| 整数 → 二进制 | `to_binary(n)` | `to_binary(10)` → `"1010"` |
| 二进制 → 整数 | `from_binary(s)` | `from_binary("1010")` → `10` |
| 整数 → 三进制 | `to_ternary(n)` | `to_ternary(21)` → `"210"` |
| 三进制 → 整数 | `from_ternary(s)` | `from_ternary("210")` → `21` |
| 二进制 → 三进制 | `binary_to_ternary(s)` | `"1010"` → `"101"` |
| 三进制 → 二进制 | `ternary_to_binary(s)` | `"210"` → `"10101"` |

支持负数（`-5 ↔ "-101"`）、零值。往返转换保持一致：`from_ternary(binary_to_ternary(b)) == from_binary(b)`。

### 11.3 Matha 专属编码

Matha 专属进制编码用前缀标记，可与传统格式互译：

| 编码 | 前缀 | 示例 | 含义 |
|------|------|------|------|
| Matha 二进制 | `M2:` | `M2:1010` | 10 的二进制 |
| Matha 三进制 | `M3:` | `M3:210` | 21 的三进制 |

```
to_matha_binary(10)        → "M2:1010"
to_matha_ternary(21)       → "M3:210"
matha_binary_to_ternary("M2:1010") → "M3:101"
matha_ternary_to_binary("M3:210")  → "M2:10101"
from_matha_code("0b1010")  → 10     （兼容传统 0b/0t/0x/十进制格式）
```

> **能力边界**：转译模块提供数值层面的进制编码转换（整数 ⇄ 二进制/三进制字符串 ⇄ Matha 专属编码）。将 Matha 代码编译为可执行二进制机器码属于编译器后端职责，超出当前规格语言范畴。
