# 自我升级子系统：探针 + 沙箱 + 升级

本文档说明 Matha 解释器的「自我升级」子系统——一套让程序在运行时
**内省自身状态、在隔离环境中试运行新代码、安全合并变更**的能力。

- **探针（Probe）**：只读内省，查看已注册的变量/函数/内建/构造子。
- **沙箱（Sandbox）**：隔离试运行，代码在本体解释器之外运行，不影响本体。
- **升级（upgrade）**：沙箱试运行 →（可选）校验 → 通过则合并到本体；失败回滚。

三件套共同实现「自我升级」：Matha 程序可在运行中加载新源码、先验证、
再决定是否提交，而坏代码无法污染已注册的函数/变量。

| 能力 | Python 侧入口 | Matha 侧内建 |
|------|---------------|--------------|
| 探针 | `interp.probe()` | `探针_状态` / `探针_已定义` / `探针_函数列表` |
| 沙箱 | `interp.sandbox()` | （由 `试运行` / `升级` 内部使用） |
| 升级 | `interp.upgrade(src, verify=...)` | `升级(源码)` / `试运行(源码)` |

---

## 1. 探针（Probe）

探针是对解释器运行时状态的**只读**视图。所有方法返回普通容器
（dict/list/bool），不暴露内部可变对象，便于跨语言边界使用。

### 1.1 Python 侧 API

通过 `interp.probe()` 获取探针实例：

```python
from src.interp import Interpreter
from src.parser import parse

i = Interpreter()
i.run(parse('func 平方(x: Int) -> Int = (x) => x * x'))
p = i.probe()
```

| 方法 | 返回 | 说明 |
|------|------|------|
| `state()` | dict | 综合状态快照（见下） |
| `env()` | dict | 变量名 → 值 的浅快照 |
| `func_names()` | list | 已注册函数名列表 |
| `builtin_names()` | list | 已注册内建名列表 |
| `has(name)` | bool | name 是否已定义（变量/函数/内建/构造子任一） |
| `func_info(name)` | dict / None | 函数参数信息；未定义返回 None |

`state()` 返回的 dict 结构：

```python
{
    "变量": [...],      # env 中的变量名
    "函数": [...],      # 已注册函数名
    "内建": [...],      # 内建名（含 ord/chr/.../升级/探针_状态 等）
    "构造子": [...],    # enum 构造子
    "输出数": int,      # outputs 列表长度
    "追踪数": int,      # trace 列表长度
    "深度": int,        # 当前递归深度（调试用）
}
```

`func_info(name)` 返回示例：

```python
p.func_info("平方")
# {"名": "平方", "参数": ["x"]}
```

### 1.2 Matha 侧内建

Matha 代码可直接调用以下内建（返回 Matha 可消费的值）：

| 内建 | 签名 | 返回 | 说明 |
|------|------|------|------|
| `探针_状态` | `探针_状态()` | dict | 等价 `probe().state()` |
| `探针_已定义` | `探针_已定义(名)` | bool | 等价 `probe().has(名)` |
| `探针_函数列表` | `探针_函数列表()` | list | 等价 `probe().func_names()` |

> **0 参调用说明**：Matha 语法层无空括号调用，但 parser 将 `()` 解析为
> `IntegerLit(0)`，故 `探针_状态()` 实为「应用 `探针_状态` 于 0」；
> 该内建忽略参数，返回状态 dict。Matha 侧无法内省 dict 字段，通常配合
> `探针_已定义` / `探针_函数列表` 这类返回标量/list 的内建使用。

示例：

```matha
#1：{
  [探针_已定义("翻倍")]      (* 假 → 真，取决于是否已升级 *)
  表 = 探针_函数列表()
  [len(表)]                 (* 已注册函数数 *)
}
```

## 2. 沙箱（Sandbox）

沙箱是隔离执行环境：克隆本体解释器的 env/funcs/constructors/builtins，
在其上运行新源码，**本体不受影响**。

### 2.1 创建与运行

```python
i = Interpreter()
i.run(parse('func 基础(x: Int) -> Int = (x) => x'))

sb = i.sandbox()                       # 创建沙箱（克隆本体状态）
outs, trace, err = sb.run(source)      # 在沙箱中运行源码
```

`sb.run(source)` 返回三元组 `(outputs, trace, error)`：
- `error is None` → 运行成功
- `error` 为字符串 → 解析或运行时出错（已捕获，不抛出）

沙箱内可调用新定义的函数，但不会进入本体：

```python
sb.run('func 新增(x: Int) -> Int = (x) => x + 1')
assert sb.call("新增", 5) == 6          # 沙箱内可调用
assert "新增" not in i.funcs            # 本体未被污染
```

### 2.2 变更检测：`diff()`

`diff()` 返回沙箱相对初始快照的变更摘要：

```python
{
    "新函数": [...],       # 新增函数名
    "改函数": [...],       # 被覆写的函数名
    "新变量": {名: 值},    # 新增变量
    "改变量": {名: 新值},  # 值被改写的变量
    "新构造子": [...],     # 新增枚举构造子
}
```

### 2.3 提交与回滚

| 方法 | 行为 |
|------|------|
| `commit()` | 将沙箱变更合并到本体（env/funcs/constructors 以 update 合并）；返回 diff |
| `rollback()` | 丢弃所有变更 |

**一次性语义**：`commit()` 或 `rollback()` 后沙箱立即作废，再次调用任何
方法会抛 `MathaRuntimeError`。

```python
sb = i.sandbox()
sb.run('func 新增A(x: Int) -> Int = (x) => x + 1')
sb.commit()                           # 合并到本体
assert "新增A" in i.funcs
sb.run("...")                         # ❌ 抛错：沙箱已 commit
```

合并策略：
- `env` / `funcs` / `constructors` 以 `update` 合并到本体（沙箱覆写优先）
- `builtins` **不合并**（升级不改 Python 内建）

### 2.4 沙箱内的 `升级` 调用：层间隔离

沙箱克隆时会**重新绑定状态化内建到沙箱自身解释器**。因此在沙箱内部调用
`升级(...)`，会在沙箱内部再开一层沙箱，变更只提交到当前沙箱，**不会泄漏到
外层本体**：

```python
i = _interp_with('func 基础(x: Int) -> Int = (x) => x')
sb = i.sandbox()
# 这段 Matha 代码在沙箱内调用 升级
src = '''#1：{
  升级("func 沙箱内(x: Int) -> Int = (x) => x + 1")
  [沙箱内(1)]
}'''
outs, _, err = sb.run(src)
assert outs == [2]                    # 沙箱内可用
assert "沙箱内" not in i.funcs        # 本体未被污染
sb.rollback()
```

## 3. 升级（upgrade）

`upgrade` 是沙箱 + 校验 + 合并的高层封装，是「自我升级」的主入口。

### 3.1 Python 侧：`interp.upgrade(source, verify=None)`

```python
result = i.upgrade(source, verify=callable_or_None)
```

流程：
1. 创建沙箱（克隆本体）
2. 在沙箱中解析 + 运行源码
3. **运行出错** → `rollback`，返回失败结果（本体未被触碰）
4. `verify` 给定时调用 `verify(sandbox)`：
   - 返回 `False` 或抛异常 → `rollback`
   - 返回 `True` → 继续
5. **通过** → `commit`，返回成功结果（含变更 diff）

返回 `UpgradeResult` 对象：

| 字段 | 类型 | 说明 |
|------|------|------|
| `成功` | bool | 是否升级成功 |
| `错误` | str / None | 失败原因（成功时为 None） |
| `输出` | list | 沙箱运行的 outputs |
| `追踪` | list | 沙箱运行的 trace |
| `变更` | dict | 成功时为 diff() 结果，失败时为 `{}` |

`UpgradeResult.as_dict()` 转为普通 dict（供 Matha/JSON 消费）。

### 3.2 用法示例

**成功升级**：

```python
i = _interp_with('func 加一(x: Int) -> Int = (x) => x + 1')
r = i.upgrade('func 立方(x: Int) -> Int = (x) => x * x * x')
assert r.成功 is True
assert "立方" in r.变更["新函数"]
assert i.call("立方", 3) == 27         # 本体立即可用
```

**运行时错误 → 回滚，本体不污染**：

```python
r = i.upgrade('#1：[未定义量]')
assert r.成功 is False
assert "未定义" in r.错误
assert "未定义量" not in i.env         # 本体未被污染
assert i.call("加一", 41) == 42        # 原有函数仍可用
```

**语法错误 → 回滚**：

```python
r = i.upgrade('func 错的(x: Int -> Int = (x) => x')   # 缺括号
assert r.成功 is False
assert "错的" not in i.funcs
```

**verify 校验通过 → 提交**：

```python
r = i.upgrade(
    'func 双倍(x: Int) -> Int = (x) => x * 2',
    verify=lambda sb: sb.call("双倍", 5) == 10,   # 在沙箱中验算
)
assert r.成功 is True
```

**verify 返回 False → 不提交**：

```python
r = i.upgrade(
    'func 错误版(x: Int) -> Int = (x) => x + 1',
    verify=lambda sb: sb.call("错误版", 5) == 100,  # 故意不满足
)
assert r.成功 is False
assert "校验" in r.错误
assert "错误版" not in i.funcs
```

**verify 抛异常 → 回滚**：

```python
def bad_verify(sb):
    raise ValueError("校验器自身出错")

r = i.upgrade('func 临时(x: Int) -> Int = (x) => x', verify=bad_verify)
assert r.成功 is False
assert "校验异常" in r.错误
```

### 3.3 Matha 侧自升级内建

Matha 代码可直接调用以下内建进行自我升级：

| 内建 | 签名 | 返回 | 失败行为 |
|------|------|------|----------|
| `升级` | `升级(源码)` | 新增/改写函数名列表 | 抛 `MathaRuntimeError` |
| `试运行` | `试运行(源码)` | bool（True=无错） | 不抛，返回 False |

> **返回值设计**：Matha 侧无法内省 dict，故 `升级` 成功时返回**函数名列表**
> （可用 `len`/`get` 消费），失败时**抛错**（已被沙箱 rollback，本体零污染）。
> `试运行` 返回 bool，便于在三元条件中分支。

**示例：运行中加载新函数并立即使用**

```matha
func 加一(x: Int) -> Int = (x) => x + 1
#1：{
  新函数 = 升级("func 翻倍(x: Int) -> Int = (x) => x * 2")
  [新函数]                  (* ["翻倍"] *)
  [翻倍(21)]               (* 42，已提交可立即调用 *)
  [探针_已定义("翻倍")]     (* 真 *)
  [探针_已定义("加一")]     (* 真 *)
  表 = 探针_函数列表()
  [len(表)]                (* 2：加一 + 翻倍 *)
}
```

**示例：试运行探测（不提交）**

```matha
#1：{
  好 = 试运行("func 临时(x: Int) -> Int = (x) => x + 1")
  坏 = 试运行("#1：[未定义量]")
  [好]                     (* 真：干净定义 *)
  [坏]                     (* 假：运行时错 *)
  [探针_已定义("临时")]     (* 假：未提交 *)
}
```

**示例：升级失败抛错**

```matha
func 根(x: Int) -> Int = (x) => x
#1：{
  升级("#1：[未定义量]")    (* 抛 MathaRuntimeError: 升级失败: ... *)
  [根(5)]                  (* 不会执行到此处 *)
}
```

## 4. 安全保证

| 保证 | 机制 |
|------|------|
| **本体零污染** | 升级失败/校验不过一律 `rollback`，本体 env/funcs/constructors 不变 |
| **解析/运行错误捕获** | `Sandbox.run` 捕获 ParseError/MathaRuntimeError，转为 error 字符串 |
| **层间隔离** | 沙箱克隆后重新绑定状态化内建到沙箱自身；沙箱内 `升级` 只提交到当前沙箱 |
| **一次性沙箱** | `commit`/`rollback` 后沙箱作废，防止误用已废弃状态 |
| **内建不可覆写** | 合并时 `builtins` 不合并，升级不改 Python 内建 |

## 5. 完整 API 速查

### Python 侧

```python
from src.interp import Interpreter
from src.selfupgrade import Probe, Sandbox, UpgradeResult, upgrade

# Interpreter 方法
i.probe()                              # → Probe
i.sandbox()                            # → Sandbox
i.upgrade(source, verify=None)         # → UpgradeResult

# Probe 方法
p.state()                              # → dict
p.env()                                # → dict
p.func_names()                         # → list
p.builtin_names()                      # → list
p.has(name)                            # → bool
p.func_info(name)                      # → dict | None

# Sandbox 方法
sb.run(source)                         # → (outputs, trace, error)
sb.call(name, *args)                   # 在沙箱中调用
sb.diff()                              # → dict
sb.commit()                            # → dict（diff），一次性
sb.rollback()                          # 一次性

# UpgradeResult 字段
r.成功 / r.错误 / r.输出 / r.追踪 / r.变更
r.as_dict()                            # → dict
```

### Matha 侧内建

| 内建 | 签名 | 返回 |
|------|------|------|
| `探针_状态` | `探针_状态()` | dict |
| `探针_已定义` | `探针_已定义(名)` | bool |
| `探针_函数列表` | `探针_函数列表()` | list |
| `试运行` | `试运行(源码)` | bool |
| `升级` | `升级(源码)` | list（失败抛错） |
