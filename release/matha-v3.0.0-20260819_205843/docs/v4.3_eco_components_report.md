## 一、VS Code 插件发布脚本

### 1.1 文件结构

```
extensions/vscode-matha/
├── package.json              # 扩展 manifest
├── language-configuration.json
├── syntaxes/matha.tmGrammar.json
├── build.py                  # 构建脚本
├── publish.py                # 发布脚本（新增）
└── src/
    ├── extension.ts
    └── completion-provider.ts
```

### 1.2 发布脚本功能

| 功能 | 说明 |
|---|---|
| 配置验证 | 检查 package.json 必需字段 |
| 依赖安装 | npm install |
| 编译 | npm run compile |
| Smoke Test | 验证语法文件和入口 |
| 打包 | vsce package → VSIX |
| 发布 | VS Marketplace / Open VSX |

### 1.3 使用方式

```bash
# 准备发布
cd extensions/vscode-matha
python publish.py

# 发布到 VS Marketplace
export VSCE_PAT=your_token
python publish.py --publish marketplace

# 发布到 Open VSX
export OVSX_PAT=your_token
python publish.py --publish openvsx

# 同时发布两个市场
python publish.py --publish both
```
