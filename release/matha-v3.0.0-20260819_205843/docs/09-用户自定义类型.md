# 09 - 用户自定义类型

> 本章定义 Matha 的用户自定义类型：结构（基于记录/集合）、代数数据类型（和类型）、类型别名、参数化类型，以及与模式匹配的配合。

---

## 1. 设计基础

Matha 的自定义类型建立在**类型论**之上：
- **积类型**（记录/结构）—— 对应集合论中的笛卡尔积子集。
- **和类型**（代数数据类型）—— 对应不相交并集。
- **类型别名** —— 同义类型。

---

## 2. 结构（积类型）

结构是命名字段的集合，对应记录。

### 2.1 定义

```
struct <Name> [*/标注/*] = {
   <field> : <type>
   | <field> : <type>
   | ...
}
```

`|` 分格字段（见 [07 §6](07-语句与控制流.md)）。

**示例**：

```
struct Point = {
   x : Int
   | y : Int
}

struct Person */非空/* = {
   name : String
   | age : Int
}
```

### 2.2 构造与访问

```
p = Point { x = 3 | y = 4 }
[] p.x                  (* [3] *)
```

- 构造：`Name { field = val | ... }`。
- 访问：`p.field`（点号访问，草案）。

> **待确认**：点号 `.` 访问 vs `<<` 索引访问。`<<` 已用于角度，故字段访问倾向用 `.`。

---

## 3. 代数数据类型（和类型）

和类型是若干构造子的不相交并集，配合模式匹配使用。

### 3.1 定义

```
enum <Name> [*/标注/*] = {
   <Constructor> [ <type> ]
   | <Constructor> [ <type> ]
   | ...
}
```

**示例**：

```
enum Color = {
   Red
   | Green
   | Blue
}

enum Shape = {
   Circle Float              (* 半径 *)
   | Rect Float Float        (* 宽、高 *)
}
```

### 3.2 构造与模式匹配

```
s = Circle 5.0

match s
   | Circle r => 3.14 * r * r
   | Rect w h => w * h
```

模式匹配详见 [07 §5](07-语句与控制流.md)。

---

## 4. 类型别名

```
type <Name> = <type_expr>
```

**示例**：

```
type Age = Int
type PointSet = Set[Point]
type BinOp = Int -> Int -> Int
```

别名与原类型等价（结构化兼容）。

---

## 5. 参数化类型（泛型）

```
struct <Name>[<typevar>] = { ... }
enum <Name>[<typevar>] = { ... }
```

**示例**：

```
struct Pair[A, B] = {
   fst : A
   | snd : B
}

enum Option[A] = {
   Some A
   | None
}

enum Result[A, E] = {
   Ok A
   | Err E
}
```

**使用**：

```
p = Pair[Int, String] { fst = 1 | snd = "a" }
x = Some 42
```

---

## 6. 递归类型

类型可递归引用自身：

```
enum List[A] = {
   Nil
   | Cons A (List[A])
}

lst = Cons 1 (Cons 2 Nil)

match lst
   | Nil => 0
   | Cons h t => h
```

## 7. 标注与自定义类型

`*/文字/*` 标注与 `*/文字*公式/*` 标注公式可附加于类型定义，声明不变量或性质：

```
struct Natural = {
   n : Int */约束*n >= 0/*   (* 约束标注公式：n 非负 *)
}

enum Order */全/* = { Buy | Sell }
```

校验见 [05-类型系统 §7](05-类型系统.md)。

## 8. EBNF 摘要

```ebnf
<type_def>   = <struct_def> | <enum_def> | <alias_def> ;
<struct_def> = "struct" , <identifier> , [<type_params>] , [ <annotation> ] , "=" , "{" , <fields> , "}" ;
<enum_def>   = "enum" , <identifier> , [<type_params>] , [ <annotation> ] , "=" , "{" , <ctors> , "}" ;
<alias_def>  = "type" , <identifier> , [<type_params>] , "=" , <type_expr> ;
<fields>     = <field> , { "|" , <field> } ;
<field>      = <identifier> , ":" , <type_expr> , [ <annotation> ] ;
<ctors>      = <ctor> , { "|" , <ctor> } ;
<ctor>       = <identifier> , [ <type_expr> ] ;
<type_params> = "[" , <typevar> , { "," , <typevar> } , "]" ;
```

> **关键字**：`struct`、`enum`、`type` 为保留关键字草案（Matha 以符号为主，仅保留少量必要关键字）。
