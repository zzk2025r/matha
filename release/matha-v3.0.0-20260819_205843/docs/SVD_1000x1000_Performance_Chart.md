## 二、性能预测模型说明

### 2.1 模型假设

```
时间 = a × n^b

其中：
  - n: 矩阵规模
  - a: 常数因子（取决于算法实现）
  - b: 复杂度指数（理论值 3.0，实际拟合 ~2.8-3.2）
```

### 2.2 稀疏加速因子

| 稀疏度 | 加速因子 | 适用场景 |
|---|---|---|
| < 90% | 1.0x | 不适用稀疏优化 |
| 90% | 2.0x | 轻度稀疏矩阵 |
| 95% | 5.0x | 中度稀疏矩阵 |
| 99% | 10.0x | 高度稀疏矩阵 |

### 2.3 R² 拟合优度

| 算法 | R² 值 | 说明 |
|---|---|---|
| 纯 Python | 0.998 | 极佳的幂律拟合 |
| NumPy | 0.995 | 极佳的幂律拟合 |
| 稀疏 SVD | 0.985 | 良好的拟合（含稀疏加速） |

## 四、关键结论

1. **NumPy 是绝对最优**：1000x1000 矩阵仅需 0.367 秒
2. **稀疏优化有价值但有限**：95% 稀疏度下加速 5x，但仍需 433 秒
3. **生产环境必须安装 NumPy**：可获得 5900 倍性能提升
4. **稀疏优化适合特定场景**：90%+ 稀疏度且无 NumPy 时启用
