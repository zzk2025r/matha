# 18 - 示例程序集

> 本章提供 Matha 程序示例，覆盖基础运算、集合操作、函数与递归、自定义类型、并发、自然语言驱动等场景。所有示例采用**新模板格式**（`？#：{...}` 整合代码块、`>>` 链式、`@：` 混合设定、`…（0/？）` 占位符）书写，可用于验证规格说明书的自洽性。
>
> **新模板核心特征**：
> - `？#：{...}` —— 代码编号 `？` 放在 `#：` 开头（跨文件共用，可用数字代替）
> - 去除段号 `#N：`，整合为单代码块
> - `#：【命令】>>【命令】` —— 单个 `【】` 不够时用多个链式 `>>`
> - `@：【内容】，变量=值` —— 命令描述与变量赋值混合
> - `#：[输出]…（0/？）【子文件】` —— 循环分数支持 `？` 占位符
> - 子文件无编号、无段号（另算）

```

   ？x >> { n | 1 <= n <= 3 }
      ch <- x

## 9. 链式 / 循环 / 跨文件拆分（新模板整合版）

> 本节演示新模板如何整合旧模板的段编号、双重循环、`>>` 链式、跨文件拆分为**单一代码块**。
>
> **新模板核心整合点**：
> 1. **去除段号**：`#1：` / `#2：` → 统一 `#：`，多段合并为一代码块
> 2. **代码编号**：`？` 或数字放在 `#：` 开头（跨文件共用）
> 3. **链式触发**：单条命令/输出不够时用 `>>` 连接多个 `【】`
> 4. **循环占位符**：`…（0/？）` 支持占位符（模板形式）与整数（可执行）
> 5. **子文件另算**：子文件以 `#：{...}` 独立，无编号无段号
> 6. **位置区分路径**：段循环后 `【子文件】`=下位补充；全局循环后 `【文件】`=分割

---

### 9.1 单条命令足够时，直接写（无需 `>>`）

```
？#：{
  【*/读取一次温度/*】
  #：【http://sensor.local/temp】
  @：【单位设定】，单位=摄氏度
  temp = 25.6
  #：[temp]
}
#：【文件】
```

> 关键点：命令 `【http://sensor.local/temp】` **独立**读取 URL，无需 `>>` 链式。

### 9.2 单条命令不够时，启用 `>>` 链式

```
？#：{
  【*/从原始数据到最终报告/*】
  #：【读取原始数据】>>【解析字段】>>【写入数据库】
  @：【数据源与目标】，源=source.csv，目标=db://localhost:5432，表=report
  records = 0
  #：[records]…（0/？）……（0/？）【report_part2.matha】
}
#：【文件】
```

> 关键点：`【读取】>>【解析】>>【写入】`——**需要多步流水线**时才启用 `>>`。
> `…（0/？）` 段级循环占位符；`……（0/？）` 全局循环占位符；`【report_part2.matha】` 跨文件路径。

### 9.3 跨 2 文件完整版（主文件 + 子文件，共用编号）

**① 主文件：06_main.matha**

```

  【*/跨文件：主文件启动与计算/*】
  #：【启动服务】>>【读取配置】>>【执行计算】

  area = x * y

  #：[端口]
  #：[area]…（0/？）【06_sub.matha】

```

**② 子文件：06_sub.matha**（无编号、无段号）

```

  #：【汇总输出】

```

> 关键语义：
> - **主文件**开头 `？` 代码编号，跨文件共用；**子文件**无编号无段号。
> - `#：[area]…（0/？）【06_sub.matha】`——段循环后 `【子文件】`=下位文件补充/扩充。
> - 多段合并为单代码块，去除冗余段号。

### 9.4 完整末行形态

```
？#：{
  【*/完整末行形态演示/*】
  #：【加载配置】>>【计算分辨率】>>【渲染输出】

> `#：[输出]…（0/？）【子文件|子文件】……（0/？）【文件/路径】`

> - `【calc_core.matha|format_util.matha】` 多子文件 `|` 分隔（下位补充）
> - `……（0/？）` 全局循环（占位符）
> - `【display_part2.matha】` 文件路径（当前文件分割）

## 10. 新旧模板对比速查表

| 维度 | 旧模板 | 新模板 |
|------|--------|--------|
| 结构 | `#1：{} #2：{} #3：[]` 多段分散 | `？#：{...}` 单代码块整合 |
| 段号 | `#N：`（从 1 起） | 无段号 |
| 代码编号 | 独立一行 `00001` | `？` 或数字前缀放在 `#：` 开头 |
| 命令链 | `#N：【】>>【】` | `#：【】>>【】`（无段号） |
| 设定 | `@N：变量=值` | `@：【内容】，变量=值` 混合 |
| 循环分数 | 仅整数 `（0/1）` | 整数 + `？` 占位符 |
| 子文件引用 | `…N（x/y）【路径】` | `…（0/？）【路径】`（去段号） |
| 多子文件 | `|` 分隔 | `|` 分隔（不变） |
| 全局循环 | `……（x/y）` | `……（0/？）`（支持占位符） |
| 子文件格式 | `#N：{...}` 带段号 | `#：{...}` 无编号无段号 |
| 文件尾 | `#：【文件】` | `#：【文件】`（不变） |
| 互转 | `old_to_new()` / `new_to_old()` | 双向兼容 |
