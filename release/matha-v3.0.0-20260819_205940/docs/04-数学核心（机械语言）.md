# 04 - 数学核心（机械语言）

> 本章定义 Matha 的**数学形式化核心层**——即"机械语言"。它是自然语言意图与可读输出之间的中间枢纽，以**集合论**与**类型论**为形式化基础，由 Matha 符号体系书写。本章是整部规格说明书的核心。

---

## 1. 定位

数学核心层在三层架构中处于中央：

```
自然语言输入  ──→  数学核心（机械语言）  ──→  可读输出
【*/文字/*】         #：...                  [] / 《文字》
```

- **输入侧**：自然语言前端（[03](03-自然语言前端.md)）将意图映射为数学核心构造。
- **输出侧**：数学核心执行后，由可读输出层（[13](13-可读输出层.md)）生成可读命令。
- **自身**：数学核心是**纯数学公式化**的——集合、关系、映射、类型、项、判断。

---

## 2. 数学核心单元（mech_unit）

一个机械语言单元由 `#：` 触发，包含一组机械语句：

```ebnf
<mech_unit>  = <generate> , <mech_body> ;        (* #： 触发 *)
<mech_body>  = { <mech_stmt> } ;
<mech_stmt>  = <binding> | <set_construct> | <iteration> | <output> | <expr> ;
```

**`#：` 的三种作用对象**（M1 走查已确认）：

| 形式 | 语义 |
|------|------|
| `#：【*/自然语言/*】` | 运行：读取并执行自然语言意图 |
| `#：<公式>` | 运行：执行公式（如 `#：？+？=？`） |
| `#：《命令》` | 生成：生成所需命令 |

> **执行 vs 生成**：`#：` 作用于自然语言/公式时为"执行运行"；作用于 `《文字》` 时为"生成命令"。后者将文字（或空白）替换为具体命令，产出命令对象。

## 3. 集合论构造

集合论是 Matha 数据构造的基础。所有数据均可视为集合或集合上的关系/映射。

### 3.1 集合构造

```ebnf
<set_construct> = "{" , <variable> , "|" , <expr> , "}" ;
```

**形式**：`{ x | 条件 }` —— 由满足条件的所有 `x` 构成的集合。

**示例**：

```
S = { x | 1 <= x <= 10 }            (* 1 到 10 的整数集合 *)
E = { n | n >> S , n + n }          (* S 中元素的二倍，>> 步进 *)
```

**多变量与多条件**（用 `|` 分格）：

```
R = { (x, y) | x >> A | y >> B | x < y }
```

> `|` 在集合构造中分格：分隔变量声明与条件、分隔多个并列条件。具体层次见 §6.2。

### 3.2 关系

关系是集合的子集，其元素为元组（笛卡尔积的子集）：

```
R ⊆ A × B
R = { (a, b) | a >> A | b >> B | 条件 }
```

**关系运算**（待 [06](06-表达式与运算符.md) 定义完整符号）：复合、逆、投影。

### 3.3 映射（函数）

映射是特殊的关系：每个原像唯一对应像。在 Matha 中，映射即函数（详见 [08-函数与抽象](08-函数与抽象.md)）：

```
f : A → B
f = { (x, y) | x >> A | y = x + 1 }     (* f(x) = x + 1 *)
```

### 3.4 笛卡尔积

```
A × B = { (a, b) | a >> A | b >> B }
```

元组 `(a, b)` 是笛卡尔积的元素。Matha 用 `( )` 表示元组与分组。

### 3.5 集合运算

| 运算 | 形式（草案） | 语义 |
|------|------------|------|
| 并 | `A ∪ B` 或 `A + B`（待确认） | 并集 |
| 交 | `A ∩ B` 或 `A * B`（待确认） | 交集 |
| 补 | `~A` 或 `A'`（待确认） | 补集 |
| 差 | `A \ B`（待确认） | 差集 |
| 属于 | `x >> S` 或 `x ∈ S`（待确认） | `>>` 在判断语境表示属于 |

> **`>>` 的双重语义**：在迭代语境为"步进到下一个"（`？x >> S`），在判断语境为"属于"（`x >> S` 为真当 x 属于 S）。具体消解见 [06-表达式与运算符](06-表达式与运算符.md)。

## 4. 类型论构造

类型论为集合构造提供类型约束，保证构造的合法性与可检查性。

### 4.1 类型与项

- **类型（Type）**：值的集合的抽象。如 `Int`、`Set[Int]`、`Int -> Int`。
- **项（Term）**：某类型下的具体值。如 `42 : Int`、`S : Set[Int]`。

### 4.2 判断（Judgement）

Matha 采用类型论的判断形式：

| 判断 | 含义 |
|------|------|
| `Γ ⊢ e : τ` | 在环境 Γ 下，项 e 具有类型 τ |
| `Γ ⊢ e1 ≡ e2 : τ` | e1 与 e2 在类型 τ 下定义相等 |
| `Γ ⊢ τ1 <: τ2` | τ1 是 τ2 的子类型 |

**示例**：

```
Γ ⊢ 42 : Int
Γ ⊢ S : Set[Int]
Γ ⊢ f : Int -> Int
```

### 4.3 类型规则（草案）

完整的类型推导规则（如 `引入规则`、`消去规则`）见 [05-类型系统](05-类型系统.md) 与 [16-形式化语义](16-形式化语义.md)。本章仅给出核心判断形式。

## 5. 符号在数学核心中的语义

本节给出 Matha 符号在数学核心层的精确语义（词法定义见 [02-词法结构](02-词法结构.md)）。

### 5.1 `#：` 生成/运行

- `#：<mech_body>` —— 执行一组机械语句。
- `#：【*/自然语言/*】` —— 读取并执行自然语言意图（映射为 mech_body）。
- `#：《命令》` —— 生成命令对象（不立即执行，交由可读输出层或运行时）。

### 5.2 `？` 公式占位

- `？` 在公式中表示**通用变量占位**，可被任意字母替代（`？ = a = g1 = c3 = m1 = Z`）。
- 主要用于**生成公式模板**：`#：？+？=？` 表示"任意两数相加"的公式模板。
- 具体程序中用具名字母：`#：a + b = c`。

### 5.3 `>>` 步进 / 属于 / 路径距离 / 链式（四重语义，统一为"下一个 / 到 / 下一级"）

`>>` 统一为"**下一个 / 到 / 下一级**"，按语境消解为四种具体语义：

| 语境 | 语义 | 示例 |
|------|------|------|
| 循环头部（后跟语句体） | **步进迭代**：变量依次取下一个元素 | `？x >> S` 后跟缩进块 → x 依次取 S 元素 |
| 表达式内部（条件、`|` 分隔处） | **属于判断**：x 属于 S → Bool | `x >> S` 返回真假 |
| **绑定/设定的左侧**（`a>>b = ...` 出现在 `=` 左边或 `@:` 项中） | **路径/距离**：从 a 到 b 的距离/路径，可直接赋值 | `a>>b = 100米` 表示 a 到 b 的距离为 100 米 |
| **链式语境**（`>>` 两侧均为语句且不在其他三语境中，M3.1 已确认） | **通用链式执行**：连接多条命令、输出或任意语句，按顺序逐条执行 | `#：【启动服务】>>【读取配置】>>【执行计算】` |

> **路径语义新确认**：用户示例中 `a>>b=100米` 表示「a 到 b 距离 = 100 米」，单位 `米` 只是附加字符串，不做特殊量纲处理（已确认：单位只是字符串）。
>
> **链式语义新确认（M3.1）**：`>>` 链式为**通用链式**，可连接任意语句类型（命令、输出、设定、公式、变量等）。消解规则：当 `>>` 两侧均为同类语句（`【】>>【】`、`[]>>[]` 等）且不在循环头/绑定左侧/表达式内部语境时，归为链式语义。

### 5.4 `<<` 角度运算

- `<<n` 表示 `n` 度角，用于三角运算：`sin(<<30)`、`cos(<<90)` 等。
- `<<` 是一元前缀角度标记，将其后的数值解释为角度（度）。

### 5.5 `^` 次方 / 开方（双语义）

`^` 同一符号按**位置**消解为两种语义（已确认）：

| 位置 | 语义 | 示例 |
|------|------|------|
| **中缀**（前有操作数） | 次方：`a^b` 为 a 的 b 次方 | `2^3 = 8`（等价 `2*2*2`）；`3^2 = 9` |
| **前缀**（前无操作数） | 开方：`^n` 为 n 的平方根 | `^9 = 3`（因 `3*3=9`）；`^16 = 4` |

- **次方**：`a^b`，右结合：`2^2^3 = 2^(2^3) = 256`。
- **开方**：`^n` 求 n 的平方根（等价 `n^(1/2)`）。开方是次方的逆运算——`^9 = 3` 因 `3^2 = 9`。

> 位置消解在语法层依据前一个 Token 判定（见 [02 §2.1](02-词法结构.md) 与 [06 §2](06-表达式与运算符.md)）。

### 5.6 `|` 分格

- 在集合构造中分隔：`{ x | 条件 }`、`{ (x,y) | 声明 | 条件 }`。
- 在序列中分隔并列单元：`a | b | c`。

### 5.7 `【】` / `〔〕` 读取

- 读取内容：`【*/文字/*】` 读取自然语言、`【《文字》】` 读取命令。
- `【】` 与 `〔〕` 等价，可互换（M1 走查已确认）。

### 5.8 `[]` 输出

- `[] <expr>` —— 输出表达式的结果，作为可读命令产出。

### 5.9 `*/文字/*` 标注与 `*/文字*公式/*` 标注公式

- `*/文字/*` 为变量/表达式附加语义约束，用于类型检查与意图明确（详见 [05-类型系统](05-类型系统.md)）。
- **标注公式扩展** `*/文字*公式/*`：标注名后可携带公式，用于细化约束与属性声明，例如 `*/约束*x >= 0/*`、`*/范围*1 <= x <= 10/*`。公式部分参与类型检查与约束验证。

### 5.10 `@` 设定（双形式）

`@` 用于**设定**一组标识符/变量/参数，有两种等价书写形式（已确认：两者都支持）：

**形式一：`@(...)` 括号分格**（紧凑、机器友好）

```
@(a1 | d | c6)                       (* 设定三个变量，| 分格 *)
@(x*/Int/* | y*/Int/* | z*/Int/*)    (* 设定并标注类型 *)
```

**形式二：`@:` 前缀 + 中文逗号分格**（手写、自然语言风格）

```
@:a>>b=100米，b>>c=50米，c>>d = (a>>c) * 3，a*/酒店/*    (* 中文逗号 ， 分格 *)
@:x*/Int/*，y*/Int/*                                    (* 可混英文逗号 @: x, y 也合法 *)
```

- 每项可携带标注（含公式扩展）：`@(a1*/Int/* | c6*/约束*c6 >= 0/*)`。
- 用于批量声明变量、参数列表、配置项、条件设定等。`|`（形式一）或 `，/ ,`（形式二）分格与集合构造中的分格语义一致。

### 5.11 `{ }` 代码块（整体串）

除了集合构造 `{ x | 条件 }` 外，`{ }` 的第二重语义是**代码块 / 整体串**：用大括号把一串代码括起来，表示"这一串代码是一个整体"（已确认）。

```
#：{
   【*/自然语言与叙述/*】
   #：《小米在 c>>d 段 1/4 下车，求小米到 a 点距离》
   ………
   #：[262.5米]
}
```

- 一个 `{...}` 块等价于一串按序执行的机械语句。
- 推荐在 `#：` 后使用 `{ }` 明确机械单元的起止，避免依赖缩进/换行的隐式边界。
- 与集合构造的歧义消解：`{` 后若紧跟 `变量 |` 或 `{ v, v, v }` 枚举形式，则为集合；否则为代码块（最外层机械单元）。

### 5.12 段编号与可编辑/不可编辑代码（用户 M3 新示例已确认）

Matha 机械单元分**可编辑**与**不可编辑（模板）**两种书写形态：

| 形态 | 段编号 | 典型场景 | 代码段内写法 |
|---|---|---|---|
| **不可编辑（模板）** | 无段号（只用 `#：`/`@：`） | 你好世界、问候、简单语句等短单元 | `#：{【*/你好，世界/*】#：[你好，世界]……（0/1）}` |
| **可编辑（分步）** | **段 1、段 2、段 3…**（段号从 1 起排列，整数任意位） | 长任务、跨文件、需要循环追踪的完整代码 | `#1：…  @1：…  #2：…  @2：… ……` |

**可编辑代码在同一个 `{ }` 块内的 5 个固定步骤（每段 N 内，顺序不可调换，M3.1 已确认）：**

| 步骤 | 写法（段 N） | 语义 | 多句分隔 | 可否省略 |
|---|---|---|---|---|
| ① 段级命令 | `#N：【命令】` 或 `#N：《命令》` | 第 N 段要执行的命令/目标（两种写法等价） | **换行**：每条命令独立一行 | 可省略 |
| ② 段级变量/设定 | `@N：变量` 或 `@N(a,b,c)` | 第 N 段的变量/条件设定 | `@N:` 用**逗号**；`@N(...)` 用 `\|` | 可省略 |
| ③ 段级 `？` 公式 | `#N：？公式` | 第 N 段的公式模板——**把数学公式简化/抽象化**（`？` 占位 / `？+？=？` 通用公式） | **逗号**分隔多条 | 可省略 |
| ④ 段级字母公式/计算 | `#N：字母公式/直接计算` | 第 N 段的计算过程——**把 `？` 公式精确化**到具体字母变量或直接数值运算 | **逗号**分隔多条 | 可省略 |
| ⑤ 段级输出 + 循环 + 路径 | `#N：[输出/结果]`（主输出行）<br>`#N：…N（x/y）[全局编号][……（g_x/g_y）][【路径】]`（循环+路径独立一行） | 第 N 段输出：主输出行与循环/路径**分行**书写（M3.2 强调的推荐写法）；同行写法仍允许作为简写 | 主输出行固定一行；循环+路径独立一行（可同行作简写） | 通常不可省略 |

> **M3.1 新增确认的语义：**
> - 「命令 → 变量 → `？`公式 → 字母公式 → 输出」的顺序是**固定的**，不可调换；但每步可按需省略。
> - `？公式` = **简化/抽象化**（用占位符 `？` 表达通用结构）；`字母公式` = **精确化**（把 `？` 替换为具体字母/数值）。
> - 命令用**换行**分格；公式/变量用**逗号**分格。

> **M3.2 细化确认的语义（在 M3.1 之上的补充）：**
> - **命令与输出各自独立拥有"读取能力"**：命令 `【…】` 与输出 `[…]` 都能独立识别并读取 **URL / 网站 / 本地文件 / 文件夹 / 端口**（见 §5.14 与 07 §2.4.5）。
> - **`>>` 链式是"单条不够用时才启用"的机制**：当**单个命令**或**单个输出**已足以完成任务 → 直接写单条；当它们**无法满足**需求（需要多个步骤、多个数据源或多段流水线） → 用 `>>` 链式把多条命令/输出/任意语句按顺序连接。
> - **段内 5 步可按需省略**：每一步都可临时省略不用，段的最小合法形态为「只有 `[输出]`」甚至「只有 `{…}` 空段」。
> - **多命令/多变量/多公式可同时存在并按需调用**：一段内允许写多条命令、多条 `？` 公式、多条字母公式；当另一段/另一命令的需求匹配某条变量或公式时，可以被**共同选用/调用**。
> - **公式分层的直观语义**：`？`公式 = **简化抽象**（把数学公式"拍扁"成通用模板）；字母公式 = **精确化**（把抽象模板还原到精确的字母变量或直接运算）。

> **M3.3 语义澄清（用户权威定义：5 步顺序的语义层级）**：
>
> 5 步顺序不只是书写格式，而是一条**从自然语言到机械语言的逐级简化链**。每一步都是上一步的进一步简化，语义层级如下：
>
> | 步骤 | 语义（用户权威定义） | 在简化链中的角色 |
> |---|---|---|
> | 自然语言意图 | 要说的话 / 要做的事 | 最上层（[03](03-自然语言前端.md) 自然语言前端的输入） |
> | ① 命令 | 从上一级（自然语言意图）拆下的多重逻辑进行多重简化 | 意图→逻辑的首次拆解 |
> | ② 变量命令 | 进一步拆解简化并赋值，带入变量，用数字 / 字母进行平替 | **自然语言到机械语言的过渡层** |
> | ③ `？`公式 | **真正自然语言**：把数学公式的字母用 `？` 进行平替与简单化，不因字母过于繁琐；`？`公式要以变量带入进行产生 | 比 ④ 更接近自然语言（`？` 平替了繁琐字母） |
> | ④ 字母公式 | `？`公式带入变量对号入座的产物并进行计算 | `？` → 具体字母 / 数值的精确化 |
> | ⑤ 输出 / 结果 | 计算结果产出 | 终点 |
> | 循环与文件路径 | — | 补充机制（§5.13 / §5.14） |
>
> **三个关键确认**：
> 1. **变量命令是 NL→ML 过渡层**——它把意图里的参数"落地"为可计算变量（用数字 / 字母平替自然语言描述），是自然语言与机械语言之间的桥梁。
> 2. **`？`公式是真正自然语言**——它比字母公式 ④ 更接近自然语言，因为用 `？` 平替了繁琐的具名字母；这是"简化"而非"精确化"。
> 3. **`？`公式依赖变量命令**——`？`公式"以变量带入进行产生"，即 ③ 必须引用 ② 已定义的变量，不能凭空出现。这与"命令→变量→？公式"的固定顺序一致：先有变量，才能把变量的通用结构抽象为 `？` 公式。
>
> 这条简化链解释了为什么简洁的自然语言意图（如"生成显示器"）能被有效分解：意图不必一次写全，而是经"命令→变量命令→？公式→字母公式→输出"逐级简化落到 mech_body（完整示例见 [03 §4.4](03-自然语言前端.md)）。

### 5.13 双重循环后缀：段级 + 全局（M3 已确认）

**层一：段级循环 `…N（x/y）`（单省略号 …，硬性区分）+ 子文件引用**
- 段级循环写在 `#N：[...]` 之后：`#1：[输出/结果]…1（0/1）`
- 含义：第 N 段**总循环 y 次，当前已执行 x 次**（x=0 表示起始）
- 括号半/全角均合法：`(0/4)` 与 `（0/4）` 等价
- `N` 是段号（通常与 `#N：` 中的段号一致，便于视觉对照）
- **段循环后可跟【子文件/路径】**（M3.3 新增）：子文件是**下位文件**，用于**补充/扩充**当前段的代码。可调用其它代码子文件，多个子文件用 `|` 分隔：
  ```
  #1：[输出/结果]…1（0/1）【sub_a.matha】            (* 单个子文件 *)
  #2：[输出/结果]…2（0/4）【sub_a.matha|sub_b.matha】  (* 多个子文件，| 分隔 *)
  ```

**层二：全局循环 `……（x/y）`（双省略号 ……，硬性区分）+ 文件路径**
- 全局循环写在**整个代码的段后缀后**或**模板末尾**
- 含义：**整个代码块总循环 y 次，当前已执行 x 次**
- 与**全局代码编号**绑定：可在段后缀后插入任意位数字作为全局编号，再跟全局循环
- **全局循环后可跟【文件/路径】**（M3.3 新增）：表示**当前代码文件被分割/分化成多个文件使用**——即本文件是某个更大代码块的一个分片，路径指向关联的其它分片。
  ```
  #2：[输出/结果]…2（0/4）【sub.matha】00001……（0/1）【file_2.matha】
  (* 段 2 循环 0/4；子文件 sub.matha 补充本段；全局编号 00001；全局循环 0/1；本文件分片关联 file_2.matha *)
  ```
- **全局代码编号不固定位数**：任意位数字都合法（M3 已确认），如 `00001`、`42`、`999999`

**完整末行形态（M3.3）**——段循环 + 子文件 + 全局编号 + 全局循环 + 文件路径：

```
#：[输出/结果]…（x/y）【子文件/路径|…】<全局编号>……（x/y）【文件/路径】
```

> **子文件 vs 文件的语义区分（M3.3 关键）**：
> - **段循环后的【子文件/路径】**= 下位文件，**补充/扩充**当前段（横向/下位扩充），可 `|` 多个。
> - **全局循环后的【文件/路径】**= 当前代码文件被**分割/分化**成多个文件（纵向分片），单一路径。
> - 两者位置固定：子文件紧跟段循环后（全局编号前），文件紧跟全局循环后。

**不可编辑模板可只写全局循环**（无需段级循环/段号）：
```
#：{【*/你好，世界/*】#：[你好，世界]……（0/1）}
#：{【*/你在家吗/*】@：变量#:[输出/结果]……（0/2）}
```

### 5.14 跨文件拆分与路径引用（M3 已确认 + M3.1/M3.3 更新）

当一串完整代码被分散在多个文件中时，使用以下规则串联：

1. **每个文件尾用 `#：【文件】` 收尾**（出现在该文件 `{ }` 块最后一行，表示「当前文件里的这部分代码到此结束」）
2. **跨文件引用/查找用 `#：【文件名称/文件夹路径】`**（用户已确认：**用于输入文件名称/文件夹（路径）**——即按路径寻找、关联其他文件；绝对路径如 `d:\trae\...` 和相对路径如 `../data/` 均合法）
3. **两种路径引用按位置区分（M3.3 细化）**：
   - **段循环后的【子文件/路径】**：下位文件，**补充/扩充**当前段；多个用 `|` 分隔。写在 `…N（x/y）` 之后、全局编号之前。
   - **全局循环后的【文件/路径】**：当前代码文件被**分割/分化**成多个文件使用，路径指向关联分片。写在 `……（x/y）` 之后。
   - 两者均可同行或分行（M3.1 已确认）：同行写在输出追踪后；分行独立一行 `#：【路径】`。
4. **全局代码编号独立一行出现在下一个文件的最开头**：用于把拆分后的后续文件与原全局编号绑定
5. **`>>` 通用链式（M3.1 已确认）**：当单条命令+输出不足以表达需求时，用 `>>` 链式连接多条命令、输出或任意语句类型。`>>` 的链式语义与原有三语义通过位置上下文消解。

```
===== 文件 part1.matha（全局编号 00001，#1/#2 段） =====
#：{【*/自然语言/*】
   #1：【启动服务】>>【读取配置】        (* 多命令链式 *)
   @1:变量
   #1：？+？=？
   #1：a+b=c
   #1：[c]…1（0/1）                    (* 输出 *)

   #2：【执行计算】
   @2:x=5米，y=3米
   #2：？*？=？
   #2：x*y=15
   #2：[15平方米]…2（0/4）【calc_helper.matha】00001……（0/2）【part2.matha】
   (* 段循环0/4；子文件calc_helper补充段2；全局编号00001；全局循环0/2；本文件分片关联part2 *)
   #：【文件】
}

===== 文件 part2.matha（同一全局编号 00001，#3 段，单独一行在开头） =====
00001
#3：{【汇总输出】
   @3:单价=10元
   #3：？*？=？
   #3:面积*单价=150
   #3：[150元]…3（0/1）00001……（0/2）
   #：【文件】
}
```

> **M3.2 新增：**
> - 命令/输出的**独立读取能力**已提升为一等语义（无需 `>>` 链式即可单独读取 URL / 文件 / 文件夹 / 端口）。
> - `>>` 链式的**触发条件**明确为：**当单个命令或单个输出无法满足需求时**才启用（多条命令/输出按顺序串联）。
> - 段内 5 步**全部可按需省略**；最小合法段形态允许只写 `[输出]` 甚至空段。

> **M3.3 新增：**
> - 段循环后缀 `…N（x/y）` 后可跟**【子文件/路径】**：下位文件，**补充/扩充**当前段，多个用 `|` 分隔。
> - 全局循环后缀 `……（x/y）` 后可跟**【文件/路径】**：当前代码文件被**分割/分化**成多个文件使用。
> - 两种路径引用**按位置区分**语义（子文件=横向扩充 / 文件=纵向分片），取代原先笼统的"同行路径引用"。

## 6. 公式化表达式

Matha 的代码即数学公式。表达式语法（完整优先级见 [06-表达式与运算符](06-表达式与运算符.md)）：

```
expr ::=  整数 | 浮点 | 字符串 | 变量
        | expr + expr | expr - expr | expr * expr | expr / expr | expr ^ expr   (* ^ 中缀次方 *)
        | ^ expr                       (* ^ 前缀开方：^9 = 3 *)
        | expr < expr | expr > expr | expr <= expr | expr >= expr | expr = expr
        | << expr                        (* 角度 *)
        | var >> expr                    (* 步进/属于 *)
        | { var | expr }                 (* 集合构造 *)
        | @( item | item ... )           (* 设定 *)
        | 【 content 】 | 〔 content 〕   (* 读取 *)
        | [ expr ]                       (* 输出 *)
        | ( expr )                       (* 分组 *)
```

## 7. 数学核心示例

### 示例 1：两数相加公式

```
#：？+？=？
```

- `#：` 运行公式
- `？+？=？` 通用占位公式（任意两数相加）
- 具体化：`#：a + b = c`（a, b, c 为具名字母）

### 示例 2：集合求和

```
#：【*/求和/*】
   S = { x | 1 <= x <= 10 }
   ？sum = 0
   ？x >> S
      sum = sum + x
   [] sum
```

执行流程：
1. `#：【*/求和/*】` 读取并执行"求和"意图
2. `S` 构造 1–10 的整数集合
3. `？sum = 0` 初始化累加变量（`？` 可换为 `sum`）
4. `？x >> S` 步进迭代：x 依次取 S 中元素
5. `sum = sum + x` 累加
6. `[] sum` 输出结果 → `[55]`

### 示例 3：生成命令

```
#：《问候》
```

- 生成名为"问候"的命令对象，交由可读输出层展示或运行时执行。

### 示例 4：角度、次方与开方

```
#：sin(<<30)              (* 30° 的正弦 *)
#：2^10                   (* 2 的 10 次方 = 1024，中缀次方 *)
#：^9                     (* 9 的平方根 = 3，前缀开方 *)
#：^16                    (* 16 的平方根 = 4 *)
```

### 示例 5：设定（双形式）

```
#：@(a1 | d | c6)         (* 形式一：括号分格 *)
#：
   @:a>>b=100米，b>>c=50米，a*/酒店/*    (* 形式二：@: + 中文逗号，设定路径距离 *)
```

### 示例 6：完整机械单元块（{ } 串代码）

```
#：{
   【*/行程问题/*】
   #：《小米从 c 到 d 段 1/4 处下车，求到 a 点距离》
   @:a>>b=100米，b>>c=50米，c>>d = (a>>c) * 3，a*/酒店/*
   #：公式模板：?+?=?, ?*?/?=?
   #：[262.5米]
}
```
