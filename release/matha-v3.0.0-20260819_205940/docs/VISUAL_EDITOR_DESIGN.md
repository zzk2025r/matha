## 三、使用方式

### 3.1 添加节点

```
1. 点击工具栏的 "+" 按钮
2. 选择节点类别
3. 点击具体节点类型
4. 节点将添加到画布中心
```

### 3.2 连接节点

```
1. 点击节点的端口（小圆点）
2. 拖动到目标节点的端口
3. 松开鼠标建立连接
```

### 3.3 移动节点

```
1. 点击并拖动节点标题栏
2. 节点将跟随鼠标移动
```

### 3.4 删除节点

```
1. 悬停节点
2. 点击右上角的 "×" 按钮
```

### 3.5 导出/导入

```
导出：点击工具栏下载按钮，复制 JSON
导入：点击工具栏上传按钮，粘贴 JSON
```
