# Matha 社区愿景与路线图

## 愿景

Matha 的愿景是成为世界上第一个真正支持中文编程的自举式编程语言，通过虚拟代码引擎实现无限扩展能力。

**核心理念**：当虚拟代码引擎足够强大时，自然语言可以直接当编程语言使用，生态系统只是一个数据库。

## 使命

- 让每个人都能用中文编程
- 提供完整的领域覆盖
- 实现真正的自举编译
- 构建开放的社区生态

## 贡献者指南

### 新手入门

1. 阅读 README.md
2. 运行 `python test_full.py`
3. 阅读 `tutorials/getting_started.md`
4. 尝试修改一个测试用例
5. 提交第一个 PR

### 领域模块贡献

1. 创建 `src/domains/my_module.py`
2. 实现 `_register_*` 函数
3. 在 `registry.py` 中注册
4. 添加测试用例
5. 提交 PR

### 文档贡献

1. 修复错别字
2. 添加代码示例
3. 翻译文档
4. 更新 API 文档
