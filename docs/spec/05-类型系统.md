# 05 - 类型系统

> 本章定义 Matha 的类型系统：基本类型、集合类型、函数类型、参数化类型，以及核心的 **`*/文字/*` 标注机制**。Matha 采用**静态强类型 + 局部推断 + 标注约束**，暂不引入依赖类型（留待后续版本）。

---

## 1. 设计目标

- **数学严谨**：类型对应集合论中的集合，类型检查即集合成员关系的验证。
- **标注防错**：`*/文字/*` 标注在书写时即明确目标，编译期防止错乱。
- **轻量推断**：函数内局部类型推断，减少冗余声明（类 Rust/Go）。
- **不引入依赖类型**：当前版本以简单类型 + 参数化类型 + 标注起步。

---

## 2. 基本类型

| 类型 | 字面量示例 | 语义 |
|------|----------|------|
| `Int` | `42`、`0`、`-7` | 任意精度整数 |
| `Float` | `3.14`、`0.5` | 浮点数 |
| `Bool` | `真` / `假`（草案） | 布尔值 |
| `String` | `"你好"` | 字符串 |
| `Unit` | `()` | 单元类型（无有意义值） |

> 布尔字面量形式（`真/假` vs `true/false`）待确认，见 [02 §9](02-词法结构.md)。

---

## 3. 集合类型

基于集合论，集合是 Matha 的一等数据结构。

```ebnf
<set_type> = "Set" , "[" , <type_expr> , "]" ;
```

| 类型 | 示例 | 语义 |
|------|------|------|
| `Set[Int]` | `{ x | 1 <= x <= 10 }` | 整数集合 |
| `Set[Float]` | `{ 1.0, 2.0, 3.0 }` | 浮点集合 |
| `Set[String]` | `{ "a", "b" }` | 字符串集合 |

**元素类型检查**：`Γ ⊢ S : Set[T]` 当且仅当 S 的所有元素具有类型 T。

---

## 4. 函数类型

函数即映射（集合论中的特殊关系）。

```ebnf
<func_type> = <type_expr> , "->" , <type_expr> ;
```

| 类型 | 语义 |
|------|------|
| `Int -> Int` | 整数到整数的函数 |
| `Int -> Int -> Int` | 柯里化二元函数（右结合） |
| `(Int, Int) -> Int` | 元组参数函数 |

**示例**：

```
f : Int -> Int
f = { (x, y) | y = x + 1 }     (* f(x) = x + 1 *)
```

---

## 5. 元组与积类型

```ebnf
<tuple_type> = "(" , <type_expr> , { "," , <type_expr> } , ")" ;
```

| 类型 | 示例 | 语义 |
|------|------|------|
| `(Int, Int)` | `(1, 2)` | 整数二元组 |
| `(Int, String)` | `(42, "x")` | 异质二元组 |

元组对应笛卡尔积的元素。

---

## 6. 参数化类型（泛型）

```ebnf
<param_type> = <identifier> , "[" , <type_expr> , { "," , <type_expr> } , "]" ;
```

| 类型 | 语义 |
|------|------|
| `Set[T]` | 元素类型为 T 的集合 |
| `Map[K, V]` | 键值映射（待标准库定义） |

> 自定义参数化类型见 [09-用户自定义类型](09-用户自定义类型.md)。

## 7. `*/文字/*` 标注机制（核心）

标注是 Matha 类型系统的灵魂——**在错误发生之前明确目标、防止错乱**。标注有两种形式：纯文字标注 `*/文字/*` 与携带公式的标注 `*/文字*公式/*`。

### 7.1 标注的形式

```ebnf
<annotation> = "*/" , <annot_text> , [ "*" , <expr> ] , "/*" ;   (* 文字 + 可选公式 *)
<annotated>  = <subject> , <annotation> ;        (* 主体 + 标注 *)
```

- **纯文字形式** `*/文字/*`：标注名为标识符或简短文字，用于类型名、意图名、性质名。
- **标注公式形式** `*/文字*公式/*`：标注名后以 `*` 分隔，跟随一个表达式公式，用于细化约束、范围声明、属性公式等。

标注可附加于多种主体：

| 主体 | 形式 | 示例 |
|------|------|------|
| 变量 | `var */约束/*` | `x */Int/*`（标注 x 为 Int） |
| 表达式 | `expr */目标/*` | `a + b */求和/*`（标注意图） |
| 自然语言意图 | `【*/标注/*】` | `【*/问候/*】`（标注意图用途） |
| 类型 | `T */性质/*` | `Int */非负/*`（细化类型，草案） |

### 7.2 标注的语义类别

| 类别 | 示例 | 形式 | 作用 |
|------|------|------|------|
| **类型标注** | `x */Int/*` | 纯文字 | 显式声明变量类型 |
| **意图标注** | `【*/求和/*】` | 纯文字 | 标注自然语言意图的用途 |
| **约束标注** | `x */约束*x >= 0/*` | 标注公式 | 细化类型约束（refinement） |
| **性质标注** | `f */纯函数/*` | 纯文字 | 标注函数性质（如纯函数、无副作用） |
| **范围标注** | `S */范围*1 <= x <= 10/*` | 标注公式 | 声明取值范围 |

### 7.3 标注与类型检查

- **类型标注**参与类型检查：`x */Int/*` 后，若 `x` 被赋以非 Int 值，编译期报错。
- **约束标注**（公式形式）参与细化检查：`x */约束*x >= 0/*` 后，若 `x` 可能为负，编译期警告/报错（需静态分析支持）。公式部分作为布尔表达式被验证。
- **范围标注**（公式形式）参与范围验证：`S */范围*1 <= x <= 10/*` 声明 x 的取值范围，越界即报错。
- **意图标注**参与意图映射：`【*/求和/*】` 引导自然语言前端将意图映射为"求和"构造。
- **性质标注**参与语义验证：`f */纯函数/*` 后，编译器验证 f 无副作用。

### 7.4 标注示例

```
？x */Int/* = 42                          (* 类型标注：纯文字 *)
S */Set[Int]/* = { n | n >> R }           (* 集合类型标注：纯文字 *)
f */纯函数/* : Int -> Int                  (* 性质标注：纯文字 *)
【*/求和/*】 计算 1 到 10 的和             (* 意图标注：纯文字 *)
x */约束*x >= 0/* = a + b                 (* 约束标注：标注公式 *)
S */范围*1 <= x <= 10/* = { x | x >> R }  (* 范围标注：标注公式 *)
@(a1*/Int/* | c6*/约束*c6 >= 0/*)         (* @ 设定中各项带标注公式 *)
```

## 8. 类型检查与推断

### 8.1 局部推断策略

- **需声明处**：函数参数、顶层绑定建议显式标注类型（或由标注提供）。
- **可推断处**：函数体内局部变量类型由右值推断。
- **标注优先**：当标注存在时，以标注为约束进行双向检查。

### 8.2 判断形式

| 判断 | 含义 |
|------|------|
| `Γ ⊢ e : τ` | 环境 Γ 下，e 具有类型 τ |
| `Γ ⊢ e */文字/* : τ` | e 具有类型 τ 且附带文字标注（类型/性质等） |
| `Γ ⊢ e */文字*φ/* : τ` | e 具有类型 τ 且满足标注公式 φ（约束/范围，φ 为布尔表达式） |
| `Γ ⊢ τ1 <: τ2` | τ1 是 τ2 的子类型 |
| `Γ ⊢ e1 ≡ e2 : τ` | e1、e2 定义相等 |

### 8.3 核心类型规则（草案）

**变量规则**：
```
  (x : τ) ∈ Γ
  ───────────
   Γ ⊢ x : τ
```

**标注规则**（文字标注）：
```
  Γ ⊢ e : τ      Γ ⊢ τ 满足文字标注 c
  ──────────────────────────────
        Γ ⊢ e */c/* : τ
```

**标注公式规则**：
```
  Γ ⊢ e : τ      Γ ⊢ φ : Bool      Γ ⊢ e 使 φ 成立
  ──────────────────────────────────────────────
            Γ ⊢ e */文字*φ/* : τ
```

**函数应用规则**：
```
  Γ ⊢ f : τ1 -> τ2      Γ ⊢ e : τ1
  ──────────────────────────────
          Γ ⊢ f e : τ2
```

**集合构造规则**：
```
  Γ, x : τ ⊢ cond : Bool
  ─────────────────────────
  Γ ⊢ { x | cond } : Set[τ]
```

完整规则集见 [16-形式化语义](16-形式化语义.md)。

## 9. 子类型与转换

- **子类型**（草案）：`Int <: Float`（整数是浮点的子类型，允许隐式提升）。
- **显式转换**：形式待定（候选 `e as Float`）。
- **隐式转换**：仅限安全的子类型提升，其他需显式。
