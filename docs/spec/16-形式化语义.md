# 16 - 形式化语义

> 本章给出 Matha 的形式化语义：操作语义、类型规则，以及类型安全性（progress 与 preservation）。本章为进阶内容，为编译器实现与程序验证提供严格基础。

---

## 1. 目标

为 Matha 提供数学上严格的语义，使得：
- 程序行为可形式化推理。
- 类型系统的健全性（soundness）可证明。
- 编译器实现可对照规格验证。

---

## 2. 语法域

形式化语义基于 [17-完整语法 EBNF](17-完整语法EBNF.md) 的核心表达式：

```
e ::=  n                    (* 整数 *)
    |  x                    (* 变量 *)
    |  ？                   (* 占位符 *)
    |  e + e | e - e | e * e | e / e | e ^ e
    |  e < e | e > e | e <= e | e >= e | e = e
    |  << e                 (* 角度 *)
    |  { x | e }            (* 集合构造 *)
    |  [ e ]                (* 输出 *)
    |  (x) => e             (* lambda *)
    |  e e                  (* 应用 *)

v ::=  n | { ... } | (x) => e   (* 值 *)
```

## 3. 类型判断

```
Γ ⊢ e : τ                 在环境 Γ 下，e 具有类型 τ
Γ ⊢ e */文字/* : τ         e 具有类型 τ 且附带文字标注（类型/性质）
Γ ⊢ e */文字*φ/* : τ       e 具有类型 τ 且满足标注公式 φ（约束/范围，φ : Bool）
```

### 3.1 核心类型规则

**整数**：
```
   ──────────
   Γ ⊢ n : Int
```

**变量**：
```
   (x : τ) ∈ Γ
   ───────────
    Γ ⊢ x : τ
```

**加法**：
```
   Γ ⊢ e1 : Int    Γ ⊢ e2 : Int
   ──────────────────────────
       Γ ⊢ e1 + e2 : Int
```

**次方**：
```
   Γ ⊢ e1 : Int    Γ ⊢ e2 : Int
   ──────────────────────────
       Γ ⊢ e1 ^ e2 : Int
```

**关系**：
```
   Γ ⊢ e1 : τ    Γ ⊢ e2 : τ
   ───────────────────────
   Γ ⊢ e1 < e2 : Bool       (* 同理 >, <=, >=, = *)
```

**角度**：
```
   Γ ⊢ e : Int
   ───────────────
   Γ ⊢ << e : Angle
```

**集合构造**：
```
   Γ, x : τ ⊢ cond : Bool
   ─────────────────────────
   Γ ⊢ { x | cond } : Set[τ]
```

**lambda**：
```
   Γ, x : τ1 ⊢ e : τ2
   ──────────────────────
   Γ ⊢ (x) => e : τ1 -> τ2
```

**应用**：
```
   Γ ⊢ e1 : τ1 -> τ2    Γ ⊢ e2 : τ1
   ──────────────────────────────
          Γ ⊢ e1 e2 : τ2
```

**标注（文字）**：
```
   Γ ⊢ e : τ    Γ ⊢ τ 满足文字标注 c
   ──────────────────────────────
           Γ ⊢ e */c/* : τ
```

**标注公式**：
```
   Γ ⊢ e : τ    Γ ⊢ φ : Bool    Γ ⊢ e ⊨ φ
   ────────────────────────────────────────
         Γ ⊢ e */文字*φ/* : τ
```

## 4. 操作语义（大步）

求值关系 `e ⇓ v` 表示表达式 `e` 求值为值 `v`：

**整数**：
```
   ─────────
    n ⇓ n
```

**加法**：
```
   e1 ⇓ n1    e2 ⇓ n2    n1 + n2 = n
   ────────────────────────────────
          e1 + e2 ⇓ n
```

**次方**：
```
   e1 ⇓ n1    e2 ⇓ n2    n1^n2 = n
   ───────────────────────────────
          e1 ^ e2 ⇓ n
```

**lambda**：
```
   ──────────────────
    (x) => e ⇓ (x) => e
```

**应用**：
```
   e1 ⇓ (x) => e    e2 ⇓ v2    [x ↦ v2]e ⇓ v
   ─────────────────────────────────────────
              e1 e2 ⇓ v
```

## 5. 类型安全性

### 5.1 Progress

**定理**（Progress）：若 `∅ ⊢ e : τ`，则 `e` 是值，或存在 `e'` 使得 `e → e'`。

> 即：良类型的封闭项不会"卡住"（stuck）。

### 5.2 Preservation

**定理**（Preservation）：若 `∅ ⊢ e : τ` 且 `e → e'`，则 `∅ ⊢ e' : τ`。

> 即：求值保持类型不变。

### 5.3 Soundness

**推论**（Soundness）：由 Progress 与 Preservation，良类型的 Matha 程序不会产生类型错误。

> **限制**：以上为草案，仅覆盖核心 λ 演算 + 算术 + 集合。channel、错误传播、自然语言前端的形式化待后续扩展。

---

## 6. 求值上下文

求值顺序用求值上下文 `E` 表达（左到右）：

```
E ::=  □ | E + e | v + E | E ^ e | v ^ E | E e | v E | ...
```

`E[e] → E[e']` 当 `e → e'`。

---

## 7. 标注的语义

标注有两类形式，在形式化语义中体现不同：

- **纯文字标注** `*/文字/*`（如 `*/Int/*`、`*/纯函数/*`）：体现为类型/性质的附带声明。
- **标注公式** `*/文字*φ/*`（如 `*/约束*x >= 0/*`）：体现为 **refine 类型判断**：

```
Γ ⊢ e */文字*φ/* : τ    ⟺    Γ ⊢ e : { x : τ | φ(x) }
```

即 `e` 的类型 τ 上附加公式约束 `φ`（布尔表达式）。完全的 refinement 类型系统为后续工作（当前版本为草案，见 [05 §7](05-类型系统.md)）。
