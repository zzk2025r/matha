# 外部语言互操作与双实现对比

本文档说明 Matha 解释器的**外部语言互操作**能力——调用其它编程语言
（Python 宿主内嵌 / 其它语言 subprocess），以及核心应用场景
**双实现对比驱动的自我升级**。

> 前置阅读：[20-自我升级子系统.md](20-自我升级子系统.md) 介绍探针与沙箱，
> 本文在此基础上增加外部语言执行与对比升级。

- **外部求值（ForeignRunner）**：执行 Python/JavaScript/Ruby 代码，宿主内嵌或子进程隔离。
- **双实现对比（DualComparator）**：Matha 函数 vs 外部参考实现，逐输入对比返回值。
- **对比升级（compare_upgrade）**：沙箱试运行 Matha 源码 → 与外部参考对比 → 通过则提交，失败回滚。

三件套共同实现「用其它语言构建参考实现，Matha 同时构建一份等价实现，
对比通过则升级 Matha 实现」的工作流。

| 能力 | Python 侧入口 | Matha 侧内建 |
|------|---------------|--------------|
| 外部求值 | `ForeignRunner().eval(lang, code, inputs)` / `interp.foreign_eval(lang, code)` | `外部求值(语言)(代码)` |
| 函数调用 | `ForeignRunner().call(lang, code, func_name, args)` | （由对比内建内部使用） |
| 双实现对比 | `DualComparator(...).compare(test_cases)` | `对比实现(函数名)(语言)(代码)(输入列表)` |
| 对比升级 | `interp` 无直接方法；`compare_upgrade(interp, ...)` | `对比升级(源码)(函数名)(语言)(代码)(输入列表)` |

---

## 1. 外部求值（ForeignRunner）

`ForeignRunner` 执行外部编程语言代码，支持两种执行模式：

| 语言 | 模式 | 隔离方式 |
|------|------|----------|
| Python | 宿主内嵌 | 独立 globals 命名空间 |
| JavaScript / Node | subprocess | 进程级（临时文件 + JSON I/O） |
| Ruby | subprocess | 进程级 |

### 1.1 Python 侧 API

```python
from src.foreign import ForeignRunner

r = ForeignRunner()
r.eval(lang, code, inputs=None)              # 求值代码
r.call(lang, code, func_name, args)          # 执行代码并调用其中函数
```

**`eval(lang, code, inputs=None)`** — 求值代码：
- Python：表达式用 `eval` 返回值；语句用 `exec` 返回 None；`inputs` 可注入变量
- 其它语言：整段脚本执行，stdout 尝试 JSON 解析，失败返回原文本

**`call(lang, code, func_name, args)`** — 执行代码并调用函数：
- Python：`exec` 定义函数后直接调用（宿主内）
- 其它语言：生成「定义 + 调用 + JSON 输出」的 wrapper 脚本，subprocess 执行后解析 stdout

### 1.2 用法示例

**Python 表达式求值**：

```python
r = ForeignRunner()
assert r.eval("Python", "1 + 2 * 3") == 7
assert r.eval("Python", "len([1, 2, 3])") == 3
assert r.eval("Python", "'ab' + 'cd'") == "abcd"
```

**Python 语句执行**（无返回值）：

```python
assert r.eval("Python", "x = 42") is None
```

**带输入变量注入**：

```python
assert r.eval("Python", "a + b", inputs={"a": 10, "b": 20}) == 30
```

**Python 函数调用**（定义 + 传参）：

```python
code = "def 平方(x): return x * x"
assert r.call("Python", code, "平方", [5]) == 25
assert r.call("Python", code, "平方", [-3]) == 9
```

**多参数函数**：

```python
code = "def 加(a, b, c): return a + b + c"
assert r.call("Python", code, "加", [1, 2, 3]) == 6
```

**返回 list/dict 结构**：

```python
assert r.eval("Python", "[1, 2, 3]") == [1, 2, 3]
assert r.eval("Python", "{'a': 1, 'b': 2}") == {"a": 1, "b": 2}
```

**未定义函数 → 抛 MathaRuntimeError**：

```python
try:
    r.call("Python", "x = 1", "不存在", [])
except MathaRuntimeError as ex:
    assert "不存在" in str(ex)
```

### 1.3 Matha 侧内建

Matha 代码通过 `外部求值` 内建求值外部代码（柯里化两参）：

| 内建 | 签名 | 返回 |
|------|------|------|
| `外部求值` | `外部求值(语言)(代码)` | 求值结果 |

```matha
#1：{
  [外部求值("Python")("1 + 2 * 3")]      (* 7 *)
  [外部求值("Python")("len(\"hello\")")]  (* 5 *)
}
```

> **柯里化说明**：Matha 函数应用是柯里化的（`f(a)(b)` 而非逗号多参），
> 多参内建通过 `_curry` 包裹实现逐参应用。详见第 4 节。

## 2. 双实现对比（DualComparator）

`DualComparator` 对同一组测试输入，分别调用 Matha 函数与外部语言函数，
逐项对比返回值，产出 `CompareResult`。

### 2.1 Python 侧 API

```python
from src.foreign import DualComparator

cmp = DualComparator(interp, matha_func, foreign_lang, foreign_code)
result = cmp.compare(test_cases)
```

构造参数：
- `interp`：已加载 Matha 函数的解释器
- `matha_func`：要对比的 Matha 函数名
- `foreign_lang`：参考实现语言（python/javascript/ruby）
- `foreign_code`：参考实现源码（定义同名函数）

`compare(test_cases)` 参数：`test_cases` 为参数列表的列表，如 `[[1,2], [3,4]]`，
每个内层 list 是一次调用的参数。

### 2.2 CompareResult 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `通过` | bool | 全部测试输入一致 |
| `总数` | int | 测试输入数 |
| `一致数` | int | 一致的输入数 |
| `差异` | list | 不一致项详情（每项含 输入/Matha结果/外部结果） |

`as_dict()` 转为普通 dict：

```python
{"通过": True, "总数": 4, "一致数": 4, "差异数": 0}
```

### 2.3 用法示例

**完全一致 → 通过**：

```python
i = _interp_with('func 平方(x: Int) -> Int = (x) => x * x')
cmp = DualComparator(i, "平方", "Python", "def 平方(x): return x * x")
result = cmp.compare([[2], [3], [5], [-1]])
assert result.通过 is True
assert result.总数 == 4 and result.一致数 == 4
```

**有差异 → 差异详情**：

```python
i = _interp_with('func 加一(x: Int) -> Int = (x) => x + 1')
cmp = DualComparator(i, "加一", "Python", "def 加一(x): return x + 2")
result = cmp.compare([[1], [2]])
assert result.通过 is False
assert result.一致数 == 0
assert len(result.差异) == 2
# 差异项结构：
assert result.差异[0] == {"输入": [1], "Matha结果": 2, "外部结果": 3}
```

**部分一致**：

```python
i = _interp_with('func f(x: Int) -> Int = (x) => (x > 2) ? x * x : x + 1')
cmp = DualComparator(i, "f", "Python", "def f(x): return x * x")
result = cmp.compare([[2], [3]])
assert result.通过 is False
assert result.一致数 == 1   # 3*3=9 一致
assert len(result.差异) == 1  # 2: Matha=3, 外部=4
```

**Matha 函数抛异常 → 差异中记录**：

```python
i = _interp_with('func 倒数(x: Int) -> Int = (x) => 1 / x')
cmp = DualComparator(i, "倒数", "Python", "def 倒数(x): return 1 / x")
result = cmp.compare([[0]])
assert result.通过 is False
assert "Matha异常" in str(result.差异[0]["Matha结果"])
```

**外部函数抛异常 → 差异中记录**：

```python
i = _interp_with('func f(x: Int) -> Int = (x) => x')
cmp = DualComparator(i, "f", "Python", "def f(x): return x / 0")
result = cmp.compare([[1]])
assert result.通过 is False
assert "外部异常" in str(result.差异[0]["外部结果"])
```

### 2.4 值对比规则

`_values_equal(a, b)` 对比 Matha 值与外部值，容忍类型差异：

| 类型组合 | 规则 |
|----------|------|
| int / float | 直接 `==`（互通：1 == 1.0） |
| bool | 严格区分（True ≠ 1） |
| str | 直接 `==` |
| list / tuple | 逐元素递归（list 与 tuple 互通） |
| dict | key/value 递归 |

```python
from src.foreign import _values_equal
assert _values_equal(1, 1.0) is True        # int/float 互通
assert _values_equal(True, 1) is False       # bool 严格
assert _values_equal([1, 2], (1, 2)) is True # list/tuple 互通
```

### 2.5 Matha 侧内建

| 内建 | 签名 | 返回 |
|------|------|------|
| `对比实现` | `对比实现(函数名)(语言)(代码)(输入列表)` | bool（全一致为 True） |

```matha
func 平方(x: Int) -> Int = (x) => x * x
#1：{
  用例 = append(append(空列表)(list(2)))(list(3))
  [对比实现("平方")("Python")("def 平方(x): return x * x")(用例)]   (* 真 *)
}
```

> **列表构造**：Matha 中 `[]` 解析为空 Output 而非空列表，故用 `空列表` 内建 +
> `append` + `list` 构造测试输入。详见第 4 节。

## 3. 对比升级（compare_upgrade）

`compare_upgrade` 是双实现对比 + 沙箱 + 合并的高层封装，是「用外部语言验证
Matha 实现」的主入口，复用自我升级子系统的安全语义。

### 3.1 Python 侧：`compare_upgrade(parent, matha_src, matha_func, foreign_lang, foreign_code, test_cases, extra_verify=None)`

```python
from src.foreign import compare_upgrade

result = compare_upgrade(
    parent,           # 本体解释器
    matha_src,        # 待升级的 Matha 源码（定义 matha_func）
    matha_func,       # 要对比的 Matha 函数名
    foreign_lang,     # 参考实现语言
    foreign_code,     # 参考实现源码（定义同名函数）
    test_cases,       # 对比用测试输入列表
    extra_verify=None # 可选额外校验 callable(sandbox) -> bool
)
```

流程：
1. 创建沙箱（克隆本体）
2. 在沙箱中加载 Matha 源码（试运行）
3. **运行出错** → rollback，返回失败（本体未被触碰）
4. 在沙箱中用 `DualComparator` 对比 Matha 函数与外部参考实现
5. **对比不通过** → rollback，返回失败（含差异详情）
6. `extra_verify` 给定时调用；返回假或抛错 → rollback
7. **全通过** → commit，返回成功（含变更 diff）

返回 `UpgradeResult`（与自我升级子系统同一类型）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `成功` | bool | 是否升级成功 |
| `错误` | str / None | 失败原因 |
| `输出` | list | 沙箱运行输出 + 对比摘要（成功时末尾含摘要 dict） |
| `追踪` | list | 沙箱运行 trace |
| `变更` | dict | 成功时为 diff() 结果，失败时为 `{}` |

### 3.2 用法示例

**对比通过 → 提交**：

```python
i = _interp_with('')
matha_src = 'func 平方(x: Int) -> Int = (x) => x * x'
py_code = "def 平方(x): return x * x"
r = compare_upgrade(i, matha_src, "平方", "Python", py_code, [[2], [3], [5]])
assert r.成功 is True
assert "平方" in r.变更["新函数"]
assert i.call("平方", 4) == 16
```

**对比不一致 → 回滚**：

```python
# Matha 实现错误（x+1 而非 x*x）
r = compare_upgrade(i, 'func 平方(x: Int) -> Int = (x) => x + 1',
                    "平方", "Python", py_code, [[2], [3]])
assert r.成功 is False
assert "对比不一致" in r.错误
assert "平方" not in i.funcs   # 本体未污染
```

**源码运行时错 → 回滚**：

```python
r = compare_upgrade(i, '#1：[未定义量]', "f", "Python",
                    "def f(x): return x", [[1]])
assert r.成功 is False
assert "加载失败" in r.错误
```

**源码语法错 → 回滚**：

```python
r = compare_upgrade(i, 'func 错(x: Int -> Int = (x) => x', "错", "Python",
                    "def 错(x): return x", [[1]])
assert r.成功 is False
assert "加载失败" in r.错误
```

**覆写已有函数**（对比通过则升级到新版）：

```python
i = _interp_with('func f(x: Int) -> Int = (x) => x + 1')
r = compare_upgrade(i, 'func f(x: Int) -> Int = (x) => x * 2',
                    "f", "Python", "def f(x): return x * 2", [[1], [2]])
assert r.成功 is True
assert "f" in r.变更["改函数"]
assert i.call("f", 3) == 6    # 新版
```

**零测试用例 → 空对比通过**：

```python
r = compare_upgrade(i, 'func f(x: Int) -> Int = (x) => x',
                    "f", "Python", "def f(x): return x", [])
assert r.成功 is True          # 无测试 → 无差异 → 通过
```

**额外校验通过**：

```python
r = compare_upgrade(i, 'func 双倍(x: Int) -> Int = (x) => x * 2',
                    "双倍", "Python", "def 双倍(x): return x * 2", [[5]],
                    extra_verify=lambda sb: sb.call("双倍", 10) == 20)
assert r.成功 is True
```

**额外校验拒绝 → 回滚**：

```python
r = compare_upgrade(i, 'func f(x: Int) -> Int = (x) => x',
                    "f", "Python", "def f(x): return x", [[1]],
                    extra_verify=lambda sb: False)
assert r.成功 is False
assert "额外校验" in r.错误
```

**输出含对比摘要**（成功时）：

```python
r = compare_upgrade(i, 'func f(x: Int) -> Int = (x) => x',
                    "f", "Python", "def f(x): return x", [[1], [2]])
assert r.成功 is True
summary = r.输出[-1]
assert summary == {"通过": True, "总数": 2, "一致数": 2, "差异数": 0}
```

### 3.3 Matha 侧内建

| 内建 | 签名 | 返回 | 失败行为 |
|------|------|------|----------|
| `对比升级` | `对比升级(源码)(函数名)(语言)(代码)(输入列表)` | 新增/改写函数名列表 | 抛 `MathaRuntimeError` |

```matha
#1：{
  用例 = append(append(空列表)(list(2)))(list(3))
  名表 = 对比升级("func 立方(x: Int) -> Int = (x) => x * x * x")("立方")("Python")("def 立方(x): return x * x * x")(用例)
  [名表]        (* ['立方'] — 对比通过，已提交 *)
  [立方(2)]     (* 8 — 本体立即可用 *)
  [立方(3)]     (* 27 *)
}
```

**对比升级失败 → 抛错**：

```matha
#1：{
  用例 = append(空列表)(list(2))
  对比升级("func 平方(x: Int) -> Int = (x) => x + 1")("平方")("Python")("def 平方(x): return x * x")(用例)
  (* 抛 MathaRuntimeError: 对比升级失败: 对比不一致... *)
}
```

## 4. Matha 侧辅助内建

外部语言互操作涉及两个辅助内建：

### 4.1 `空列表` — 空列表值

Matha 中 `[]` 被解析为空 Output（输出语句），而非空列表。为构造列表（如对比升级的
测试输入），提供 `空列表` 内建作为空列表字面量：

```matha
#1：{
  表 = append(append(空列表)(1))(2)   (* [1, 2] *)
  [len(表)]        (* 2 *)
  [get(表)(0)]     (* 1 *)
  [get(表)(1)]     (* 2 *)
}
```

配合 `append(列表)(元素)` 追加元素、`list(x)` 构造单元素列表、`get(列表)(下标)` 取元素。

### 4.2 多参内建的柯里化

Matha 函数应用是柯里化的（`f(a)(b)` 而非 `f(a, b)`），多参 Python 内建通过
`_curry(n, func)` 包裹实现逐参应用。以下内建均为柯里化：

| 内建 | 参数数 | 用法 |
|------|--------|------|
| `外部求值` | 2 | `外部求值(语言)(代码)` |
| `对比实现` | 4 | `对比实现(函数名)(语言)(代码)(输入列表)` |
| `对比升级` | 5 | `对比升级(源码)(函数名)(语言)(代码)(输入列表)` |

## 5. 安全保证

| 保证 | 机制 |
|------|------|
| **外部代码隔离** | Python 在独立 globals 命名空间运行；其它语言在子进程运行 |
| **本体零污染** | 对比升级失败/不一致/校验不过一律 rollback，本体不变 |
| **错误捕获** | ForeignRunner 捕获外部异常；DualComparator 捕获两侧异常记入差异 |
| **沙箱层间隔离** | 对比在 Sandbox 内进行；沙箱内调用 `对比升级` 会再开一层沙箱 |
| **进程级超时** | subprocess 模式有 30 秒超时，防止外部代码挂起 |

from src.foreign import ForeignRunner, DualComparator, CompareResult, compare_upgrade

## 7. 典型工作流

**用 Python 参考实现验证 Matha 升级**：

```python
from src.interp import Interpreter
from src.parser import parse
from src.foreign import compare_upgrade

# 1. 本体已有旧实现
i = Interpreter()
i.run(parse('func 排序(表: List) -> List = (x) => x'))  # 占位旧版

# 2. Python 参考实现
py_ref = """
def 排序(表):
    return sorted(表)
"""

# 3. Matha 新实现（待升级）
matha_new = '''
func 排序(表: List) -> List =
  (表) => (len(表) <= 1) ? 表 : 合并(取左半(表))(取右半(表))
# ... 合并/取左半/取右半 等辅助函数定义
'''

# 4. 对比升级：多组测试输入
cases = [[3, 1, 2], [5, 4], [1], []]
r = compare_upgrade(i, matha_new, "排序", "Python", py_ref, cases)

if r.成功:
    print(f"升级成功：{r.变更['新函数']}")
    print(f"本体 排序([3,1,2]) = {i.call('排序', [3, 1, 2])}")
else:
    print(f"升级失败：{r.错误}")
```

**Matha 侧自对比升级**：

```matha
#1：{
  用例 = append(append(空列表)(list(3, 1, 2)))(list(5, 4))
  名表 = 对比升级("func 平方和(a: Int, b: Int) -> Int = (a) => (b) => a * a + b * b")("平方和")("Python")("def 平方和(a, b): return a * a + b * b")(用例)
  [名表]
  [平方和(3)(4)]
}
```
