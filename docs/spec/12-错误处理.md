# 12 - 错误处理

> 本章定义 Matha 的错误处理机制：基于代数数据类型 `Result`/`Option` 的显式错误传播、`*/文字/*` 标注的错误边界，以及运行时错误。

---

## 1. 设计哲学

Matha 摒弃异常（exception），采用**代数数据类型**显式表示可能失败的计算，理由：
- **数学严谨**：错误是值，可被类型系统检查。
- **可读可验证**：错误路径在代码中显式，无隐藏的控制流跳转。
- **标注防错**：`*/可能错误/*` 标注明确哪些计算可能失败。

---

## 2. 错误类型

基于 [09-用户自定义类型](09-用户自定义类型.md) 的和类型：

```
enum Option[A] = { Some A | None }
enum Result[A, E] = { Ok A | Err E }
```

- `Option[A]`：可能有值（`Some v`）或无值（`None`）。
- `Result[A, E]`：可能成功（`Ok v`）或失败（`Err e`），E 为错误类型。

**标准错误类型**（草案，见 [14-标准库概要](14-标准库概要.md)）：

```
enum MathError = {
   DivByZero
   | OutOfRange String
   | ChannelClosed
   | ParseError String
}
```

---

## 3. 错误传播

### 3.1 模式匹配处理

```
div : Int -> Int -> Result[Int, MathError] = (a, b) =>
   b = 0 ? Err DivByZero : Ok (a / b)

match div 10 0
   | Ok v => [] v
   | Err DivByZero => [] "除零错误"
```

### 3.2 传播操作符（草案）

`?` 后缀（半角，与全角占位 `？` 不冲突）提前传播错误：

```
process = (a, b) =>
   v = div a b ?        (* 若 div 失败，立即返回 Err *)
   [] v * 2
```

`expr ?` 表示：若 `expr` 为 `Err`，则当前函数立即返回该 `Err`；若 `Ok v`，则解构为 `v`。

> **待确认**：`?` 传播操作符 vs 强制 `match`。`?` 提升简洁性，但引入隐式控制流。

---

## 4. 标注与错误边界

`*/文字/*` 标注在错误处理中的作用：

| 标注 | 语义 |
|------|------|
| `*/可能错误/*` | 标注函数可能返回错误，提示调用者处理 |
| `*/无错误/*` | 标注函数绝不失败（纯且完全） |
| `*/可能空/*` | 标注可能返回 `None` |

**示例**：

```
sqrt */可能错误/* : Float -> Result[Float, MathError] = (x) =>
   x < 0 ? Err (OutOfRange "负数") : Ok (sqrt_impl x)

const */无错误/* : Int -> Int = (x) => x
```

**错误边界**：模块/函数可声明 `*/无错误/*` 边界，编译器验证其内部不产生未处理错误。

---

## 5. 运行时错误

少数情况产生运行时错误（无法静态避免）：

| 错误 | 触发 |
|------|------|
| `ChannelClosed` | 向已关闭 channel 发送 |
| `栈溢出` | 无限递归 |
| `内存耗尽` | 资源不足 |

运行时错误**不被 `Result` 捕获**，会终止程序并输出诊断信息（见 [13-可读输出层](13-可读输出层.md)）。可由 `*/可能错误/*` 边界标注提示风险。

---

## 6. 与可读输出层的衔接

错误结果可通过 `[]` 输出，便于人检验：

```
match div 10 0
   | Ok v => [] v
   | Err e => [] e          (* [DivByZero] *)
```

错误诊断信息（位置、调用栈）由可读输出层格式化，见 [13-可读输出层](13-可读输出层.md)。

---

## 7. EBNF 摘要

```ebnf
<error_type>  = "Result" , "[" , <type> , "," , <type> , "]" | "Option" , "[" , <type> , "]" ;
<propagate>   = <expr> , "?" ;        (* 错误传播，草案 *)
<match_error> = "match" , <expr> , { "|" , ( "Ok" | "Err" | "Some" | "None" ) , <pattern> , "=>" , <expr> } ;
```
