# 13 - 可读输出层

> 本章定义 Matha 的**可读输出层**：`[]` 输出符号的语义、`《文字》` 命令展示、数学公式展示、三段式对比，以及调试信息。这是 Matha"可读可验证"哲学的核心载体。

---

## 1. 定位

可读输出层是三层架构的出口（见 [00-前言与概述](00-前言与概述.md)）：

```
自然语言输入  →  数学核心执行  →  可读输出
【*/文字/*】      #：...            [] / 《文字》
```

**核心信条**：若生成的命令无法被人读懂，则无法被信任。可读输出是一等公民，非可选调试功能。

---

## 2. `[]` 输出符号

### 2.1 语法

```
[ <expr> ]            (* 输出表达式的结果 *)
[]                    (* 空输出，草案 *)
```

### 2.2 输出格式

`[]` 将表达式的值格式化为可读文本：

| 值类型 | 输出形式 | 示例 |
|--------|---------|------|
| 整数 | 数字 | `[] 42` → `[42]` |
| 字符串 | 文本 | `[] "你好"` → `[你好]` |
| 集合 | 元素列表 | `[] {1, 2, 3}` → `[{1, 2, 3}]` |
| 元组 | `(a, b)` | `[] (1, 2)` → `[(1, 2)]` |
| 错误 | 错误名 | `[] DivByZero` → `[DivByZero]` |

输出用方括号 `[ ]` 包裹，与读取符号 `【】`/`〔〕` 区分。

### 2.3 示例

```
[] 2 + 3              (* [5] *)
[] "你好，Matha"      (* [你好，Matha] *)
[] { x | 1 <= x <= 3 }   (* [{1, 2, 3}] *)
```

## 3. `《文字》` 命令展示

### 3.1 命令对象

`#：《命令》` 生成命令对象（见 [04-数学核心 §5.1](04-数学核心（机械语言）.md)）。可读输出层负责将命令对象**展示为可读形式**：

```
#：《问候》            (* 生成"问候"命令 *)
```

输出展示：

```
《问候》
   命令: 输出"你好，Matha"
   状态: 已生成
```

### 3.2 命令的执行与展示

命令对象可被执行或仅展示。展示模式供人审阅；执行模式由 `#：` 触发运行：

```
#：《问候》            (* 生成命令 *)
[] 《问候》            (* 展示命令，草案 *)
```

> **待确认**：命令展示的格式、命令对象的字段（命令名、参数、状态）。

## 4. 数学公式展示

Matha 的代码即数学公式。可读输出层可将数学核心的构造**以数学公式形式**展示：

```
数学核心：
   S = { x | 1 <= x <= 10 }
   sum = Σ x   (x ∈ S)

可读输出（公式形式）：
   Σ_{x=1}^{10} x = 55
```

公式展示便于数学审阅，与符号化代码形成对照。

---

## 5. 三段式对比展示

可读输出层的核心能力：将**自然语言意图、数学核心、可读输出**三段并排展示，供人逐层检验：

```
① 自然语言意图
   【*/求和/*】 计算 1 到 10 的和

② 数学核心
   #：【*/求和/*】
      S = { x | 1 <= x <= 10 }
      ？sum = 0
      ？x >> S
         sum = sum + x
      [] sum

③ 可读输出
   [55]
```

**对比展示模式**（编译器选项，草案）：`matha --compare program.matha` 输出三段对照表。

---

## 6. 调试信息

可读输出层在错误或诊断场景提供：

| 信息 | 内容 |
|------|------|
| 位置 | 文件、行、列 |
| 调用栈 | 函数调用序列 |
| 标注追溯 | 相关 `*/文字/*` 标注 |
| 三段对照 | 出错处的自然语言 vs 数学核心 |

**示例**：

```
错误: 除零
位置: program.matha:12:5
标注: */求和/*
数学核心: sum = sum / (x - x)
自然语言: 计算 1 到 10 的和
```

---

## 7. 输出目标

可读输出可导向：

| 目标 | 用途 |
|------|------|
| 终端 | 交互运行 |
| 文件 | 持久化记录 |
| 三段对照报告 | 审阅与验证 |
| 调试器接口 | IDE 集成（草案） |

## 8. EBNF 摘要

```ebnf
<output>       = "[" , <expr> , "]" | "[" , "]" ;
<cmd_display>  = "《" , <command> , "》" ;         (* 命令展示 *)
<compare_mode> = "①" , <nl_block> , "②" , <mech_unit> , "③" , <output> ;   (* 三段对照，概念性 *)
```
