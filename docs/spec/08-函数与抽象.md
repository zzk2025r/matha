# 08 - 函数与抽象

> 本章定义 Matha 的函数：函数定义、参数与返回值、高阶函数、闭包与 lambda、递归，以及 `*/文字/*` 标注对函数的约束（纯函数、性质标注）。

---

## 1. 函数即映射

在 Matha 中，函数是集合论中的**映射**（特殊关系）。函数类型 `A -> B` 表示从 A 到 B 的映射（见 [05-类型系统 §4](05-类型系统.md)）。

---

## 2. 函数定义

### 2.1 命名函数

```
<name> [*/标注/*] : <类型> = <body>
```

**示例**：

```
inc */纯函数/* : Int -> Int = (x) => x + 1
add */纯函数/* : (Int, Int) -> Int = (a, b) => a + b
```

- 函数名后可跟 `*/标注/*`（如 `*/纯函数/*`，声明性质）。
- 类型声明 `: A -> B`。
- `(x) => body` 为 lambda 体。

### 2.2 简写形式（草案）

对单表达式函数，可省略 `=>`，用数学等式风格：

```
inc(x) = x + 1
add(a, b) = a + b
```

> **待确认**：简写形式是否需要类型声明，或由推断/标注提供。

---

## 3. Lambda 与闭包

### 3.1 Lambda 表达式

```
(<参数>) => <expr>
```

```
(x) => x * x              (* 平方 *)
(a, b) => a + b           (* 加法 *)
```

### 3.2 闭包

Lambda 捕获定义环境的变量：

```
n = 10
addn = (x) => x + n       (* 捕获 n *)
```

---

## 4. 高阶函数

函数可作为参数与返回值：

```
apply : (Int -> Int, Int) -> Int = (f, x) => f x
twice : (Int -> Int) -> (Int -> Int) = (f) => (x) => f (f x)

compose : (Int -> Int) -> (Int -> Int) -> (Int -> Int)
        = (f) => (g) => (x) => f (g x)
```

**示例**：

```
inc = (x) => x + 1
double = (x) => x * 2
h = compose inc double       (* h(x) = inc(double(x)) = 2x + 1 *)
[] h 5                       (* [11] *)
```

---

## 5. 递归

函数可递归调用自身：

```
fact */纯函数/* : Int -> Int = (n) =>
   n <= 1 ? 1 : n * fact(n - 1)

[] fact 5                    (* [120] *)
```

**集合论视角的递归**：递归函数可表示为不动点 `fix f`，其中 `f : (A -> B) -> (A -> B)`。Matha 提供 `fix`（草案，标准库）。

---

## 6. `*/文字/*` 标注对函数的约束

| 标注 | 语义 | 校验 |
|------|------|------|
| `*/纯函数/*` | 无副作用，仅依赖输入 | 编译器验证无赋值外部状态、无 IO |
| `*/全/*` | 对所有输入有定义 | 验证覆盖性（如模式匹配完备） |
| `*/单射/*` | 输出唯一对应输入 | 草案，需静态分析 |
| `*/Int/*`（类型标注） | 参数/返回类型 | 类型检查 |

**示例**：

```
sort */纯函数/* */全/* : Set[Int] -> Set[Int] = (S) => ...
```

---

## 7. `？` 在函数中的应用

`？` 作为公式占位，可用于定义通用函数模板：

```
#：？+？=？                (* 通用加法公式 *)
```

具化后等价于具名函数。`？` 不参与运行时，仅用于公式生成与符号化推理。

---

## 8. 柯里化与部分应用

Matha 函数默认柯里化：`A -> B -> C` 等价 `A -> (B -> C)`。

```
add : Int -> Int -> Int = (a) => (b) => a + b
add5 = add 5               (* 部分应用，add5 : Int -> Int *)
[] add5 3                  (* [8] *)
```

---

## 9. EBNF 摘要

```ebnf
<func_def>   = <identifier> , [ <annotation> ] , ":" , <func_type> , "=" , <lambda> ;
<lambda>     = "(" , <params> , ")" , "=>" , <expr> ;
<params>     = <param> , { "," , <param> } ;
<param>      = <variable> , [ <annotation> ] ;
<func_app>   = <expr> , <expr> ;
```
