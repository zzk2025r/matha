# 14 - 标准库概要

> 本章给出 Matha 标准库的概要：集合操作、数学函数、字符串、IO、并发原语，以及自然语言前端的意图模板库。本章为概要，具体实现签名以最终标准库文档为准。

---

## 1. 模块组织

标准库按模块组织（见 [10-模块系统](10-模块系统.md)）：

| 模块 | 内容 |
|------|------|
| `Set` | 集合论运算 |
| `Math` | 数学函数 |
| `String` | 字符串操作 |
| `IO` | 输入输出 |
| `Chan` | 并发原语 |
| `Template` | 自然语言意图模板 |

---

## 2. Set 模块（集合操作）

| 函数 | 签名 | 语义 |
|------|------|------|
| `union` | `Set[T] -> Set[T] -> Set[T]` | 并集 `A ∪ B` |
| `intersect` | `Set[T] -> Set[T] -> Set[T]` | 交集 `A ∩ B` |
| `diff` | `Set[T] -> Set[T] -> Set[T]` | 差集 `A \ B` |
| `complement` | `Set[T] -> Set[T]` | 补集 `~A` |
| `product` | `Set[A] -> Set[B] -> Set[(A,B)]` | 笛卡尔积 `A × B` |
| `member` | `T -> Set[T] -> Bool` | 属于 `x >> S` |
| `subset` | `Set[T] -> Set[T] -> Bool` | 子集 `A ⊆ B` |
| `map` | `(A -> B) -> Set[A] -> Set[B]` | 映射 |
| `filter` | `(A -> Bool) -> Set[A] -> Set[A]` | 过滤 |
| `reduce` | `((A, B) -> A) -> A -> Set[B] -> A` | 归约 |
| `size` | `Set[T] -> Int` | 基数 |

**示例**：

```
use Set { map | filter | reduce }
S = { x | 1 <= x <= 10 }
evens = filter (x => x % 2 = 0) S
sum = reduce (a, b => a + b) 0 evens
[] sum            (* [30] *)
```

---

## 3. Math 模块（数学函数）

| 函数 | 签名 | 语义 |
|------|------|------|
| `sin` / `cos` / `tan` | `Angle -> Float` | 三角函数（接收 `<<n` 角度） |
| `asin` / `acos` / `atan` | `Float -> Angle` | 反三角 |
| `sqrt` | `Float -> Result[Float, MathError]` | 平方根（负数返错） |
| `pow` | `Float -> Float -> Float` | 幂（等价 `^`） |
| `log` / `ln` | `Float -> Float` | 对数 |
| `abs` | `Int -> Int` / `Float -> Float` | 绝对值 |
| `floor` / `ceil` / `round` | `Float -> Int` | 取整 |
| `gcd` / `lcm` | `Int -> Int -> Int` | 最大公约/最小公倍 |
| `fix` | `((A -> B) -> (A -> B)) -> (A -> B)` | 不动点（递归） |

**示例**：

```
use Math { sin }
[] sin(<<30)            (* [0.5] *)
[] 2^10                 (* [1024] *)
```

|------|------|------|

## 5. IO 模块

| 函数 | 签名 | 语义 |
|------|------|------|
| `print` | `String -> Unit` | 输出（等价 `[]`） |
| `read` | `Unit -> String` | 读取输入 |
| `readFile` | `String -> Result[String, MathError]` | 读文件 |
| `writeFile` | `String -> String -> Result[Unit, MathError]` | 写文件 |

> IO 操作破坏纯函数性，不可标注 `*/纯函数/*`（见 [08 §6](08-函数与抽象.md)）。

---

## 6. Chan 模块（并发原语）

| 函数 | 签名 | 语义 |
|------|------|------|
| `chan` | `Type -> Chan[T]` | 创建无缓冲 channel |
| `send` | `Chan[T] -> T -> Unit` | 发送（`ch <- v`） |
| `recv` | `Chan[T] -> T` | 接收（`<- ch`） |
| `close` | `Chan[T] -> Unit` | 关闭 |
| `select` | 多 channel 等待 | 见 [11 §4](11-并发模型.md) |

---

## 7. Template 模块（意图模板）

自然语言前端的意图模板库（见 [03-自然语言前端 §3.3](03-自然语言前端.md)）：

| 模板 | 标注 | 映射目标 |
|------|------|---------|
| Greeting | `*/问候/*` | `[] "..."` |
| Sum | `*/求和/*` | 集合构造 + 迭代累加 |
| Filter | `*/过滤/*` | `filter` |
| Count | `*/计数/*` | 迭代计数 |
| Sort | `*/排序/*` | 标准库排序 |

> 模板库随版本扩展，用户可自定义模板（草案）。
