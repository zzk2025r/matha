# 10 - 模块系统

> 本章定义 Matha 的模块系统：模块定义、导入/导出、命名空间、可见性，以及多模块程序的组装方式。

---

## 1. 设计目标

- **命名隔离**：避免大型程序的名字冲突。
- **复用**：模块作为可复用的代码单元。
- **可见性控制**：区分公开接口与私有实现。
- **可读可验证**：模块边界清晰，便于分层检验。

---

## 2. 模块定义

```
module <Name> [*/标注/*] = {
   <声明>...
}
```

模块是一组声明（绑定、函数、类型）的集合，用 `{ }` 包裹（与集合构造通过上下文消歧：`module` 关键字后为模块）。

**示例**：

```
module Geometry */公开/* = {
   struct Point = { x : Int | y : Int }
   dist */纯函数/* : Point -> Float = (p) => ...
   origin : Point = Point { x = 0 | y = 0 }
}
```

---

## 3. 导入与导出

### 3.1 导出

默认模块内声明为**私有**。用 `*/公开/*` 标注声明为公开：

```
module M = {
   helper */私有/* : Int -> Int = ...      (* 草案：默认私有，标注可显式 *)
   f */公开/* : Int -> Int = ...
   struct Point */公开/* = { ... }
}
```

> **可见性标注**：`*/公开/*`（public）、`*/私有/*`（private，默认）。候选：`*/内部/*`（internal，模块内可见）。

### 3.2 导入

```
use <Module>                       (* 导入模块，用 Module.item 访问 *)
use <Module> { <name> | <name> }   (* 选择性导入，直接用 name *)
use <Module> as <Alias>            (* 别名 *)
```

`|` 分格多个导入名（见 [07 §6](07-语句与控制流.md)）。

**示例**：

```
use Geometry
use Geometry { Point | dist }
use Geometry as G

p = Geometry.Point { x = 3 | y = 4 }     (* 限定名 *)
d = dist p                                 (* 选择性导入后直接用 *)
```

---

## 4. 命名空间

- 限定名：`Module.item`，点号访问模块成员。
- 嵌套模块：`module A.B = { ... }` 表示 A 下的子模块 B（草案）。
- 命名空间不冲突：不同模块的同名成员通过限定名区分。

---

## 5. 模块组装

一个 Matha 程序由若干模块组成。程序入口（草案）为顶层 `#：` 单元或显式 `main`：

```
module Main = {
   use Geometry { Point | dist }

   main */公开/* = #：
      p = Point { x = 3 | y = 4 }
      [] dist p
}
```

> **待确认**：程序入口形式（`main` 函数 vs 顶层 `#：` 单元 vs `#：《运行》`）。

---

## 6. 模块与文件

- **草案**：一个文件一个模块，模块名与文件名对应（如 `geometry.matha` → `module Geometry`）。
- 跨文件导入通过文件路径解析（具体规则待 [15-编译执行模型](15-编译执行模型.md) 确认）。

---

## 7. 标注与模块

`*/文字/*` 标注在模块层的作用：

| 标注 | 语义 |
|------|------|
| `*/公开/*` | 模块/成员对外可见 |
| `*/私有/*` | 仅模块内可见（默认） |
| `*/内部/*` | 同一程序内可见（草案） |
| `*/废弃/*` | 标记弃用，编译器警告 |

---

## 8. EBNF 摘要

```ebnf
<module_decl> = "module" , <module_name> , [ <annotation> ] , "=" , "{" , { <decl> } , "}" ;
<import_decl> = "use" , <module_name> , [ "{" , <import_list> , "}" ] , [ "as" , <identifier> ] ;
<import_list> = <identifier> , { "|" , <identifier> } ;
<decl>        = <binding> | <func_def> | <type_def> | <module_decl> | <import_decl> ;
```
