### A.6 段编号 / 循环后缀 / 全局编号 / 文件拆分（M3 新增）

| 符号 | 名称 | 语义 | 硬性规则 | 章节 |
|------|------|------|---------|------|
| `#N:` 或 `#N：` | 段级生成/运行 | 第 N 段的命令 / 公式 / 计算 / 输出入口 | N 从 **1** 起排列，任意位整数（不允许 0 开头段号） | 02/04/07 |
| `@N:` / `@N：` / `@N(...)` | 段级设定 | 第 N 段的变量/条件/路径设定 | `@N:` 冒号半/全角都允许；等价 `@N(...|...)` 分格 | 02/04/07 |
| `…`（单省略号，U+2026 × 1） | 段级循环 | 段级局部循环后缀：`…N(x/y)` | **硬性区分：单 `…` 仅用于段级循环，不得出现在全局层** | 02/04/06/07 |
| `……`（双省略号，U+2026 × 2） | 全局循环 | 整个代码/全局编号的循环后缀：`……(x/y)` | **硬性区分：双 `……` 仅用于全局循环，不得出现在段内层级** | 02/04/06/07 |
| `(x/y)` 或 `（x/y）` | 循环分数 | 循环控制：x = 当前执行次数，y = 最大允许次数（0 表示不执行） | 半角 `()` 与全角 `（）` 等价；`/` 是分数线不是除号 | 02/04/06 |
| `00001` 等任意位数字 | 全局代码编号 | 跨文件绑定的唯一标识（一个完整代码共用一个编号） | **任意位都行，位数不固定**（支持 1、001、00001 等） | 02/04/07/17 |
| `#：【文件】` | 文件/段尾结束标记 | 放在每段 `{}` 尾行，表示当前文件里这段代码到此结束 | 路径内容严格为字符串「文件」两字 | 02/04/07 |
| `#：【文件名】` / `#：【文件夹】` / `#：【绝对路径】` | 文件/路径引用 | 按输入的文件名称或文件夹路径查找并引用对应文件 | 文件名/文件夹/相对路径/绝对路径都合法（M3 已确认） | 02/04/07 |

## G. 文档版本与状态

- **版本**：0.6 草案（M3.2 细化版）
- **里程碑**：M1（总览骨架）+ M2（核心定义）+ M3（可编辑代码结构：段编号/双重循环/跨文件拆分/可编辑与不可编辑）+ M3.1（`>>` 通用链式/段内顺序/公式语义）+ **M3.2（资源独立读取 / 链式触发条件 / 多命令多公式并存 / 循环+路径分行）** + M4（运行时与实现）+ 收尾（EBNF/示例/附录）均已完成
- **本轮新增确认项（M3.2 用户示例走查 · 细化）**：
  1. **命令与输出各自独立拥有"读取能力"**：命令 `【…】` 与输出 `[…]` 都能独立识别并读取 **URL / 网站 / 本地文件 / 文件夹 / 端口**（无需 `>>` 链式）。
  2. **`>>` 链式的触发条件（收紧）**：**当单个命令或单个输出不足以完成任务时** 才启用 `>>` 链式；否则优先使用命令/输出的独立读取能力。
  3. **段内 5 步可按需省略**：每一步都可临时省略不用，段的最小合法形态允许只写 `[输出]`。
  4. **多命令/多变量/多公式可同时存在并按需调用**：段内允许多条命令、多条 `？` 公式、多条字母公式；当另一段/另一命令的需求匹配某条变量或公式时，可**共同选用/调用**。
  5. **公式分层的直观语义**：`？` 公式 = **简化抽象**（把数学公式"拍扁"成通用模板）；字母公式 = **精确化**（把抽象模板还原到精确的字母变量或直接运算）。
  6. **循环+路径推荐分行书写**：段内第 5 步主输出行 `[输出]` 与循环/路径行 `…N(x/y)…【路径】` 分别独立一行，提升可读性。
- **本轮新增确认项（M3 用户示例走查）**：
  1. **段序号从 1 起排列 + 任意位整数**：段 ID 必须 `≥1`，长度不限（`1`/`2`/`10`/`100`…）；`#N:` 与 `#N：`、`@N:` 与 `@N：` **半/全角冒号都允许**
  2. **省略号硬性区分**：
     - 单个 `…`（U+2026×1）仅表示 **段级循环**
     - 双个 `……`（U+2026×2）仅表示 **全局循环**
     - 两者不做容错降级，数量不对直接报错
  3. **分数括号半/全角都可**：`(0/1)` 半角 与 `（0/1）` 全角 **完全等价**；分数线 `/` 仅在配对 `(…/…)` 内才是循环分数，不与除法 `/` 混淆
  4. **全局代码编号任意位都行**：跨文件绑定的全局编号数字 **位数不固定**，`1`、`001`、`00001`、`123456789` 都合法
  5. **`#：【文件】` 作为结束标记；`#：【路径】` 按路径查找文件/文件夹**：
     - `#：【文件】` → 结束当前文件里的这一部分代码（置于每段 `{}` 尾行）
     - `#：【path】` → 用于输入文件名称 / 文件夹（路径），按路径查找引用；文件名、文件夹名、相对路径、绝对路径都合法
  6. **可编辑代码 vs 不可编辑（模板）代码**：
     - 不可编辑（模板）= 无段号 + 只用 `#：`/`@：`（短单元）
     - 可编辑（分步任务）= 段 1、2、3…（任意位整数）+ 段级/全局双重循环 + 可跨文件拆分（长任务）
- **前序已确认项（M2 用户示例走查）**：
  - 语言定位：**形式化高级语言**（见 [15 §6](15-编译执行模型.md)）
  - `^` 双语义：中缀次方 / 前缀开方（`^9=3`）
  - `@` 设定双形式（已确认：两者都支持）
    - `@(a|b|c)`：括号 + `|` 分格（紧凑/机器风格）
    - `@:a，b，c`：前缀 `@:`（半角冒号）或 `@：`（全角冒号） + 中文逗号 `，`（或英文逗号 `,`）分格（手写/自然语言风格）
  - `>>` 统一为「下一个 / 到 / 下一级」三语义：
    - 循环头部 → 步进迭代（`？x >> S {体}`）
    - 表达式内部 → 属于判断（`x >> S` 真假）
    - 绑定/设定左侧 → 路径/距离（`a>>b=100米`）
  - 单位（`米/秒/千克` 等）：**纯字符串**，只作为数值标签，不做量纲换算
  - `{ }` 代码块（串代码整体）：与集合构造共存，最外层机械单元推荐使用
  - 标注公式扩展：`*/文字*公式/*`（标注可携带表达式，用于约束/范围/业务语义）
  - `<=`/`>=` 主流形式已统一全库
- **待确认项**：散见于各章末尾的"待确认项"小节（集合运算符号、布尔字面量、模式匹配语法、`?` 错误传播等）
- **后续**：规格定稿后进入 Python 编译器实现阶段（另行计划）
