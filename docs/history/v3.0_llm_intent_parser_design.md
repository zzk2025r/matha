# Matha v3.0 — LLM 集成意图解析器设计

> 将现有基于正则的 IntentClassifier 替换为 LLM API 驱动的智能解析器，
> 同时保留正则作为快速路径（fallback），实现"LLM 主导 + 正则兜底"的双层架构。

---

## 1. 现状问题分析

### 1.1 当前实现

```python
# src/intent_parser.py — 当前正则匹配
_ARITHMETIC_PATTERNS = [
    (r'计算|算|求|加减乘除|加上|减去|乘以|除以|平方|开方|幂|次方', IntentType.ARITHMETIC),
    (r'总和|合计|累加|求和|平均|均值', IntentType.ARITHMETIC),
]

def classify(self, text: str) -> IntentType:
    scores = {}
    for pattern, intent_type in self._ARITHMETIC_PATTERNS:
        if re.search(pattern, text_lower):
            scores[intent_type] = scores.get(intent_type, 0) + 1
    # 返回得分最高的类型
```

### 1.2 核心缺陷

| 缺陷 | 表现 | 影响 |
|---|---|---|
| **无语义理解** | "对数" vs "对数组" 需手动加负向前瞻 | 中文歧义无法处理 |
| **无法多轮对话** | 每次 `parse()` 独立，无上下文 | 无法追问缺失参数 |
| **意图覆盖有限** | 仅 12 种 IntentType | 复杂任务（如"写个排序程序"）失败 |
| **置信度粗糙** | 关键词计数，无概率校准 | 0.3 阈值一刀切 |
| **代码生成模板化** | 字符串拼接，非真正编译 | 复杂逻辑生成质量差 |

## 2. 架构设计

### 2.1 双层解析架构

```
┌─────────────────────────────────────────────────────────────────┐
│                     Matha LLM 意图解析器                         │
│                                                                 │
│  ┌─────────────┐    ┌──────────────┐    ┌──────────────────┐   │
│  │ 快速路径     │    │  LLM 路径     │    │  混合路径         │   │
│  │ (正则)       │───▶│ (Claude/GPT) │───▶│ (结果融合)        │   │
│  │ <50ms       │    │ <2000ms      │    │                  │   │
│  └─────────────┘    └──────────────┘    └────────┬─────────┘   │
│                                                  │              │
│                            ┌─────────────────────▼──────────┐   │
│                            │   结构化输出 (JSON Schema)      │   │
│                            │   intent_type + params + code  │   │
│                            └─────────────────────┬──────────┘   │
│                                                  │              │
│                            ┌─────────────────────▼──────────┐   │
│                            │   机械语言生成 (MIR)            │   │
│                            │   符合"代码即数学"核心原则       │   │
│                            └────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 关键设计原则

1. **LLM 不直接生成可执行代码** — 只生成结构化意图 + MIR 代码
2. **正则作为快速路径** — 简单意图 <50ms 响应，复杂意图走 LLM
3. **结果可验证** — LLM 输出的 MIR 必须通过类型检查
4. **降级策略** — LLM 失败时回退到正则，不阻塞用户

## 3. 实现方案

### 3.1 LLM 解析器核心类

```python
# src/intent_parser_llm.py
from __future__ import annotations
import json
import time
from typing import Optional
from dataclasses import dataclass, field

from src.intent_parser import Intent, IntentType
from src.result import Ok, Err
from src.errors import ClassifyError, ParamExtractError


# ============================================================
# JSON Schema 定义（LLM 输出结构约束）
# ============================================================

INTENT_JSON_SCHEMA = {
    "type": "object",
    "properties": {
        "intent_type": {
            "type": "string",
            "enum": [it.name for it in IntentType],
            "description": "意图类型"
        },
        "description": {
            "type": "string",
            "description": "意图的中文描述"
        },
        "params": {
            "type": "object",
            "description": "提取的参数（键值对）"
        },
        "confidence": {
            "type": "number",
            "minimum": 0.0,
            "maximum": 1.0,
            "description": "置信度 0-1"
        },
        "mir_code": {
            "type": "string",
            "description": "生成的机械语言代码（MIR 格式）"
        },
        "follow_up_questions": {
            "type": "array",
            "items": {"type": "string"},
            "description": "需要追问用户的问题列表（可选）"
        }
    },
    "required": ["intent_type", "description", "params", "confidence"]
}


# ============================================================
# LLM 意图解析器
# ============================================================

class LLMIntentParser:
    """基于 LLM API 的意图解析器（v3.0 核心组件）。

    支持的后端：
      - claude (Anthropic)
      - gpt (OpenAI)
      - deepseek (DeepSeek)
      - local (Ollama 本地模型)

    使用方式：
        parser = LLMIntentParser(api_key="sk-...", model="claude-3-5-sonnet")
        result = parser.parse("计算 100 以内所有素数")
    """

    # 系统提示词模板
    SYSTEM_PROMPT = """\
你是一个数学计算意图解析器。用户用自然语言描述计算任务，
你需要将其转换为结构化的机械语言（MIR）代码。

核心原则：
1. 代码即数学 — 生成的 MIR 必须是数学公式化的，而非命令式代码
2. 精确性 — 参数提取必须精确，不猜测缺失信息
3. 可验证性 — 生成的 MIR 必须能通过类型检查

如果用户输入模糊或参数缺失，在 follow_up_questions 中列出需要澄清的问题。
"""

    # 用户提示词模板
    USER_PROMPT_TEMPLATE = """\
用户输入：{text}

请解析用户的计算意图，输出 JSON：
{{
  "intent_type": "<类型>",
  "description": "<中文描述>",
  "params": <参数对象>,
  "confidence": <0-1>,
  "mir_code": "<机械语言代码>",
  "follow_up_questions": [<需要追问的问题>]
}}
"""

    def __init__(
        self,
        api_key: str,
        model: str = "claude-3-5-sonnet",
        base_url: Optional[str] = None,
        timeout: float = 10.0,
    ):
        self.api_key = api_key
        self.model = model
        self.base_url = base_url
        self.timeout = timeout
        self._api_client = None  # 延迟初始化

    def _get_client(self):
        """延迟获取 API 客户端。"""
        if self._api_client is None:
            if "claude" in self.model:
                from anthropic import Anthropic
                kwargs = {"api_key": self.api_key}
                if self.base_url:
                    kwargs["base_url"] = self.base_url
                self._api_client = Anthropic(**kwargs)
            elif "gpt" in self.model or "4o" in self.model:
                from openai import OpenAI
                kwargs = {"api_key": self.api_key}
                if self.base_url:
                    kwargs["base_url"] = self.base_url
                self._api_client = OpenAI(**kwargs)
            else:
                raise ValueError(f"不支持的模型: {self.model}")
        return self._api_client

    def parse(self, text: str, strict: bool = True) -> tuple[Intent, Optional[list[str]]]:
        """解析自然语言，返回 (Intent, follow_up_questions)。

        Args:
            text: 用户输入的自然语言
            strict: 是否严格模式（置信度 < 0.7 时返回错误）

        Returns:
            (Intent, follow_up_questions) — follow_up_questions 非空时表示需要追问
        """
        if not text or not text.strip():
            raise ValueError("输入不能为空")

        user_prompt = self.USER_PROMPT_TEMPLATE.format(text=text.strip())

        client = self._get_client()
        start = time.perf_counter()

        try:
            if "claude" in self.model:
                response = client.messages.create(
                    model=self.model,
                    max_tokens=1024,
                    system=self.SYSTEM_PROMPT,
                    messages=[{"role": "user", "content": user_prompt}],
                    response_format={"type": "json_object"},
                )
                raw_json = response.content[0].text
            else:  # OpenAI
                response = client.chat.completions.create(
                    model=self.model,
                    messages=[
                        {"role": "system", "content": self.SYSTEM_PROMPT},
                        {"role": "user", "content": user_prompt},
                    ],
                    max_tokens=1024,
                    response_format={"type": "json_object"},
                    timeout=self.timeout,
                )
                raw_json = response.choices[0].message.content or "{}"

        except Exception as e:
            raise RuntimeError(f"LLM API 调用失败: {e}") from e

        elapsed_ms = (time.perf_counter() - start) * 1000

        # 解析 JSON 响应
        try:
            data = json.loads(raw_json)
        except json.JSONDecodeError as e:
            raise RuntimeError(f"LLM 返回无效 JSON: {e}") from e

        # 验证必要字段
        required = ["intent_type", "description", "params", "confidence"]
        for field in required:
            if field not in data:
                raise RuntimeError(f"LLM 响应缺少字段: {field}")

        # 构建 Intent 对象
        try:
            intent_type = IntentType[data["intent_type"]]
        except KeyError:
            intent_type = IntentType.UNKNOWN
            data["intent_type"] = "UNKNOWN"

        intent = Intent(
            intent_type=intent_type,
            description=data["description"],
            params=data.get("params", {}),
            target_lang="mir",  # 默认生成 MIR
            confidence=float(data["confidence"]),
            suggested_code=data.get("mir_code", ""),
            parse_time_ms=elapsed_ms,
        )

        follow_up = data.get("follow_up_questions", [])
        return intent, follow_up if follow_up else None

    def parse_with_fallback(
        self, text: str, regex_parser=None
    ) -> tuple[Intent, Optional[list[str]], str]:
        """LLM 解析 + 正则兜底。

        返回 (intent, follow_up_questions, source) — source 标识解析来源
        """
        # 1. 先尝试 LLM
        try:
            intent, follow_up = self.parse(text)
            if intent.confidence >= 0.7 and not follow_up:
                return intent, follow_up, "llm"
        except Exception as e:
            # LLM 失败，记录日志
            import logging
            logging.warning(f"LLM 解析失败，回退到正则: {e}")

        # 2. 回退到正则
        if regex_parser:
            intent = regex_parser.parse(text)
            return intent, None, "regex"

        raise RuntimeError("LLM 和正则解析均失败")
```

### 3.2 集成到 EnhancedIntentParser

```python
# src/enhanced_intent.py — 修改 parse() 方法

class EnhancedIntentParser(IntentParserBase):
    """增强意图解析器 — 集成 LLM + 正则双层架构。"""

    def __init__(self, llm_parser: Optional[LLMIntentParser] = None):
        super().__init__()
        self.llm_parser = llm_parser  # 可选，None 时纯正则

    def parse(self, text: str, target_lang: str = "mir") -> Result:
        """解析自然语言，返回 Result[Intent, MathaError]。"""
        if not text or not text.strip():
            return Err(classify_error("输入为空"))

        # Step 1: 尝试 LLM 解析
        if self.llm_parser:
            try:
                intent, follow_up = self.llm_parser.parse(text)
                if follow_up:
                    # 需要追问，返回特殊错误类型
                    return Err(ClassifyError(
                        message=f"需要澄清: {follow_up}",
                        stage=ErrorStage.CLASSIFYING,
                        suggestions=follow_up,
                    ))
                if intent.confidence >= 0.7:
                    # LLM 解析成功，直接使用
                    intent.target_lang = target_lang
                    return Ok(intent)
            except Exception as e:
                # LLM 失败，继续正则
                pass

        # Step 2: 正则解析（快速路径）
        intent = self._regex_classify(text)
        if intent.intent_type == IntentType.UNKNOWN:
            return Err(classify_error(
                "无法识别意图",
                candidates=[it.name for it in IntentType if it != IntentType.UNKNOWN]
            ))

        # Step 3: 参数提取
        param_result = self._extract_params(text, intent)
        if param_result.is_err():
            intent.errors.append(param_result.err())
            intent.confidence = max(0.0, intent.confidence - 0.1)

        # Step 4: 生成 MIR 代码
        code_result = self._generate_mir(intent)
        if code_result.is_ok():
            intent.suggested_code = code_result.unwrap()

        return Ok(intent)
```

## 4. 性能与成本分析

### 4.1 延迟对比

| 场景 | 正则解析 | LLM 解析 | 混合模式 |
|---|---|---|---|
| 简单算术 | 5ms | 800ms | 5ms（正则命中） |
| 复杂意图 | 失败 | 1500ms | 1500ms |
| 模糊输入 | 失败 | 需追问 | 需追问 |
| API 故障 | 降级 | 失败 | 5ms（正则兜底） |

### 4.2 成本估算

| 模型 | 价格（每 1K tokens） | 典型解析成本 |
|---|---|---|
| Claude 3.5 Sonnet | $3 / $15 | ~$0.005/次 |
| DeepSeek V3 | $0.14 / $0.28 | ~$0.0003/次 |
| GPT-4o | $2.5 / $10 | ~$0.004/次 |
| Ollama (本地) | 免费 | 硬件成本 |

**建议**：日常使用用 DeepSeek（成本低 10x），重要场景用 Claude（质量高）。

```python
# 相似查询缓存（减少 LLM 调用）
from functools import lru_cache
import hashlib

def _cache_key(text: str) -> str:
    return hashlib.md5(text.encode()).hexdigest()

_cached_results = {}

def parse_with_cache(text: str, max_cache: int = 1000) -> Result:
    key = _cache_key(text)
    if key in _cached_results:
        return _cached_results[key]
    result = parser.parse(text)
    if len(_cached_results) >= max_cache:
        _cached_results.pop(next(iter(_cached_results)))
    _cached_results[key] = result
    return result
```

```python
# tests/test_intent_parser_llm.py
class TestLLMIntentParser(unittest.TestCase):
    """LLM 意图解析器测试。"""

    def test_parse_arithmetic(self):
        """测试算术意图解析。"""
        intent, follow_up = parser.parse("计算 3 加 5")
        self.assertEqual(intent.intent_type, IntentType.ARITHMETIC)
        self.assertGreaterEqual(intent.confidence, 0.7)
        self.assertIsNone(follow_up)

    def test_parse_with_follow_up(self):
        """测试需要追问的场景。"""
        intent, follow_up = parser.parse("求正弦值")
        self.assertIsNotNone(follow_up)
        self.assertTrue(any("参数" in q for q in follow_up))

    def test_fallback_to_regex(self):
        """测试 LLM 失败时回退到正则。"""
        # 模拟 LLM 失败
        parser.llm_parser.parse = lambda *a, **k: (_ for _ in []).throw(RuntimeError("API error"))
        intent, _, source = parser.llm_parser.parse_with_fallback("计算 3+5")
        self.assertEqual(source, "regex")
        self.assertNotEqual(intent.intent_type, IntentType.UNKNOWN)

    def test_mir_code_generation(self):
        """测试 MIR 代码生成质量。"""
        intent, _ = parser.parse("找出 1 到 100 的素数")
        self.assertTrue(len(intent.suggested_code) > 0)
        # MIR 代码必须包含数学符号
```
