## 一、集成架构设计

### 1.1 整体流程

```
┌─────────────────────────────────────────────────────────────┐
│                    输入矩阵流                                │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 稀疏矩阵检测 (_is_sparse_matrix)                    │
│  - 计算稀疏度 = 零元素数 / 总元素数                          │
│  - 阈值: 90%（可配置）                                       │
└─────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
    ┌─────────────────┐               ┌─────────────────┐
    │   稀疏矩阵      │               │   稠密矩阵      │
    │  (≥90% 零元素)  │               │  (<90% 零元素)  │
    └─────────────────┘               └─────────────────┘
              │                               │
              ▼                               ▼
    ┌─────────────────┐               ┌─────────────────┐
    │ 稀疏 SVD 优化    │               │ 标准 SVD        │
    │ - Lanczos 迭代  │               │ - NumPy SVD     │
    │ - 非零索引预计算 │               │ - 幂迭代法      │
    │ - 前 k 个奇异值 │               │ - 完整分解      │
    └─────────────────┘               └─────────────────┘
              │                               │
              └───────────────┬───────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 并行执行（可选）                                    │
│  - ThreadPoolExecutor 分发任务                               │
│  - 4-8 线程并行处理矩阵流                                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 结果聚合与返回                                      │
│  - 收集所有并行任务结果                                      │
│  - 按顺序返回奇异值、特征向量等                              │
└─────────────────────────────────────────────────────────────┘
```

## 三、命令行使用示例

### 3.1 基本使用

```bash
# 仅运行矩阵计算（标准 SVD）
python src/demos/demo_calculus_matrix.py --mode matrix

# 启用稀疏矩阵优化
python src/demos/demo_calculus_matrix.py --mode matrix --sparse

# 启用并行计算
python src/demos/demo_calculus_matrix.py --mode matrix --parallel

# 组合使用：稀疏优化 + 并行计算
python src/demos/demo_calculus_matrix.py --mode matrix --sparse --parallel --workers 4
```

### 3.2 调试模式
