## 安装命令

```bash
# 安装核心依赖
pip install -r requirements_core.txt

# 安装全部依赖（推荐）
pip install -r requirements.txt

# 或手动安装
pip install sympy numpy scipy numba pytest pytest-cov black flake8

# 升级所有依赖
pip install --upgrade pip sympy numpy scipy numba pytest black flake8
```
