# Matha AI Assistant — 小白友好型数学计算平台

> ⚠️ **定位标注（P2 降级）**：本目录所属的 AI 助手（`src/ai_assistant*.py`）是仓库内
> **未背书、零门禁** 的实验性前端，**不作为主线 v4.6.0 的现功能主张**；下述自然语言
> 解析为模板/正则规则，非真实模型。口径见仓库根 `docs/KNOWN_ISSUES.md` 第七节 7c。

> 🧮 实验性演示：自然语言示例 · 仅供参考

## 快速开始

### Web 版（零安装，最推荐小白）

```bash
# 1. 确保已安装 Python 3.10+
# 2. 启动服务
python src/ai_assistant_server.py

# 3. 浏览器打开 http://localhost:8080
# 手机/平板在同一 WiFi 下访问本机 IP:8080
```

### 桌面版

```bash
python src/ai_assistant_desktop.py
```

### 演示模式

```bash
python main.py --demo
```

## 小白使用指南

### 你可以这样问：

| 你说 | 效果 |
|---|---|
| `计算 3 加 5` | 输出 8 |
| `求 100 的平方根` | 输出 10 |
| `找出 1 到 100 的素数` | 列出所有素数 |
| `求 [1,2,3,4,5] 的平均值` | 输出 3.0 |
| `计算 5 的阶乘` | 输出 120 |
| `自由落体 3 秒` | 计算下落距离 |
| `斜抛 30度，速度 20` | 计算射程 |
| `解释什么是素数` | 概念讲解 |
| `help` | 显示帮助 |

### 内置数学概念库

- 加法、乘法、除法
- 平方、开方
- 平均值、统计
- 素数、阶乘
- 三角函数
- 物理公式（自由落体、斜抛等）

## 跨平台发布

### PWA（手机/平板安装）
在 Chrome/Safari 中打开网页 → 添加到主屏幕 → 像原生 App 一样使用

### Electron 桌面应用
```bash
# 构建
pip install electron-builder
electron-builder --win --mac --linux
```

### 打包为exe（Windows）
```bash
pip install pyinstaller
pyinstaller --onefile --windowed src/ai_assistant_desktop.py
```
